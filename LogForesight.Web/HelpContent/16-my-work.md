# 我的交辦：三分鐘上手

「我的交辦」列出指派給你的工作。每一張交辦單是一個問題，可能包含好幾台主機。
處理人登入後會直接進到這頁。
只有能處理交辦單的人，側欄才有「我的交辦」。
主管與開發人員沒有這個項目。他們自己開這一頁，會看到「你的角色沒有處理能力」。
畫面說明：交辦單只會派給有處理能力的人。需要處理交辦時，請管理者調整你的群組角色。

## 先看哪裡

頁面上方有兩排數字。
第一排是「今天需要你處理」：今天新增、復發、被退回、觀察到期、3 天內到期。
點有數字的那一張，清單就只留那一批單。清單上方會寫「只看：…」，點「清除」回到完整清單。
第二排是「目前存量」：進行中單、待我處理、觀察期內、上報中、逾期台數、未回覆單。
「待我處理」、「觀察期內」、「上報中」加起來，就是進行中的台數。

- 狀態篩選預設是「待我處理」。要看觀察期內或上報中的單，請改選「進行中」。
- 「排序」預設是「處理優先序」：被退回的、逾期的、嚴重度高的、期限近的排前面。
- 「排序」另有期限最近、嚴重度、最新建立、成員最多、最久未回覆。
- 勾「只看暫停的單」可找出問題正在靜音的單。
- 狀態篩選改成「已結案」或「全部」，可找已完成的工作。
- 頁面頂端出現「清單有更新」時，點「重新載入」就會看到最新的單。

## 看懂清單

| 欄位 | 意思 |
|---|---|
| 嚴重度 | 這張單問題的嚴重程度，看不出來時顯示「—」 |
| 主機 | 「進行中 N 台；歷來 M 台、K 件」。台是不重複的主機，件是一台主機的一個問題 |
| 標記 | 「新 N」今天新增、「復發 N」、「退回 N」、「觀察到期 N」，是 0 就不顯示 |
| 期限 | 預計完成日。夜間新派的單依嚴重度帶期限：高 3 天、中 7 天 |

## 常用操作：回覆一張交辦單

1. 在單的那一列點選「回覆」。回覆表單一定會打開，對象預設是這張單全部進行中的主機。
2. 只處理好其中幾台時，點表單裡的「只回覆部分主機」，再勾選主機。
3. 也可以貼上多個主機名，用換行、逗號或空白隔開，系統會自動勾選。找不到的名稱會列出來。
4. 選「這次的結論」，例如處理中、觀察中、已處理、誤報、已知雜訊。這一項不會預選，沒選就不能送出。
   評估後不處理選「不處理（評估後決定）」，做不到選「無法處理（上報管理者）」。
5. 寫處理說明：做了什麼、查到什麼原因、還有什麼要確認。
6. 送出。

也可以點單的那一列展開主機清單，勾選後點「回覆選取的主機」。

**注意：**只修好三台，就不要把說明套到整張九十六台的單。

- 選「處理中」時，送出鈕會寫「更新說明（不結案）」。
- 「觀察中」要填「預計完成日／觀察至」。可點「3 日」、「7 日」、「14 日」快速填入，預設 7 日。
- 「不處理（評估後決定）」與「無法處理（上報管理者）」要寫原因。
- 選「不處理（評估後決定）」、「誤報」或「已知雜訊」，表單會多一行提醒。
- 提醒寫：這台主機的這個問題之後不會再派給任何人。
- 需要恢復，請找管理者。
- 部分主機回覆為已處理等結案狀態後，表單會問「其餘 N 台要一起設為…」。
- 其餘主機要一起設定，就再選一次結論送出。不需要就關閉表單。
- 送出成功的提示會寫出結論，例如「已回覆 20 台為已處理」。
- 同一批主機做了相同處理，可以一次套用相同說明。不同處理請分開回覆。
- 回覆被拒絕時，訊息會留在畫面上，直到你關閉。你寫的說明還留在草稿裡。
- 常見原因是單剛改派給別人。訊息會寫出新的處理人，也可以複製說明。

## 復發與觀察到期

- 同一台主機的同一個問題，30 天內已處理結案又出現，會標「復發」。
- 回覆含復發主機時，表單頂端有三個建議：還在處理、觀察 7 日、請管理員評估調整規則或靜音。
- 點「請管理員評估調整規則或靜音」，會選「無法處理」並預填說明。你已寫的說明不會被蓋掉。
- 選「已處理」不會被擋。
- 觀察中的主機會寫「觀察期間再發生 N 天」、「沒有再發生」或「無資料」。
- 「無資料」是觀察期間沒有分析紀錄，不代表沒有再發生。
- 在交辦單頁最上方點「把到期且沒有再發生的 N 台結案」，可一次結案這些主機。
- 點了會先確認，說明會寫「觀察期滿未再發生」。系統不會自動結案。

## 省時間的小工具

- 「常用語」、「帶入上一張的說明」、「沿用此問題上次的說明」可以少打字，帶入後仍要逐字確認。
- AI 可用時，說明欄有「AI 整理」。它只整理你寫的內容，不會替你補上沒做的事。整理後不滿意可按「復原」。
- 「送出並回覆下一張」會接著打開下一張單。下一張有多台主機時，對象預設是全部進行中主機。
- 送出前請確認對象。
- 「期限」欄可以直接改預計完成日：已有期限，點日期旁的鉛筆鈕；還沒有期限，點「設定期限」。不會改到處理說明與狀態。
- 用手機看時，每張單只留問題與「回覆」鈕，嚴重度、主機數、逾期、未回覆與期限在問題下面一行。

## 草稿與批次回覆

- 沒送出的文字會在這台電腦的瀏覽器儲存成草稿。草稿不是正式紀錄。
- 你主動登出時，草稿會被清除。
- 翻頁時已勾選的單會保留。改篩選條件會清除勾選。
- 批次回覆：勾選要回覆的單，點選「回覆選取的單（全部進行中主機）」。送出前看一下「已選 N 張」的張數，包括其他頁勾選的。
- 只有部分成功時，照提示找出失敗的單再送一次。

## 看懂畫面上的提示

- 「目前沒有待我處理的交辦單」：預設篩選是空的。改選「進行中」，看觀察期內或上報中的單。
- 「目前沒有被指派的工作」：清單是空的，沒有待辦。
- 「你可以看到的主機目前有 N 個未處理問題（影響 M 台）」：沒有指派給你的單。
- 點「查看未處理問題」，可到問題查詢看這些問題。
- 「目前沒有進行中的交辦」：「依主機」頁籤沒有進行中的交辦。
- 「尚未被授權任何主機」：請管理員幫你設定授權。
- 「你的角色沒有處理能力」：你的角色不處理交辦單，這頁本來就沒有內容。
- 交辦單連到風險日詳情時，點問題列展開，看「來源觀測」核對來源。沒儲存的資訊會顯示「未知」，不要自己推測。
- 你只是因為交辦才看得到某台主機時，只能看被交辦的問題，不含主機整體的 PRTG 資訊。
- 點選頁面最下方的「進階檢視：依主機、被指派的風險日」展開，可以換個角度看同一批工作。

## 常見狀況

- 通知信的連結打不開、單已改派或沒有權限：回到「我的交辦」確認。
- 信裡有「代為結案」：管理者替你結案了，不必再回覆。
- 信裡有「取消」：管理者取消了這張單，裡面的主機已調回未處理。你不必回覆。
- 取消後問題若仍出現，夜間派工可能重新派工給你。
- 信裡有「移交」：這張單的部分主機改由別人處理。移出的主機你不用再處理，也不必回覆。
- 信裡有「退回」：你標為「無法處理」的主機被管理者退回，已改回處理中。請重新處理並回覆。
- 信的結尾寫「這些單不需要你再回覆」，表示信裡只有知會的項目，不必動作。
- 信裡有「靜音暫停」：這個問題被靜音，單暫停處理，到期自動恢復。
- 信裡有「靜音恢復」：靜音提前解除，請繼續處理。
- 同一個問題併進你已有的單時，信裡寫「新增成員」，不會另開新單。
- 信裡的「只看今天新增的單」、「只看被退回的單」連結，打開後清單會直接套用篩選。
- 頁面上方出現「目前暫停接單」：夜間自動派工不會再派新單給你。
- 暫停接單只影響新的自動派工，已經在你名下的單不受影響。要恢復請找系統管理員。
- 畫面載入失敗：重新整理或聯絡管理員，不要當成沒有問題。
