# 問題負責與靜音

這頁設定「某個問題由誰長期負責」，以及要不要讓某個問題暫時安靜。
入口是側欄「系統管理 > 問題負責與靜音」，需要系統維護權限。

一個「問題」由來源（Source）加上 Event ID（事件編號）決定。
同一個問題出現在不同主機，仍算同一個。

## 常用操作：指派問題負責人

1. 點選「新增規則」。
2. 選問題：從「近 30 天」出現過的清單挑選，清單依影響主機數排序。
3. 清單找不到時，點選「找不到？改為手動輸入」，填來源與 Event ID（Linux 的 Event ID 填 0）。
4. 勾選一位或多位負責人，可輸入關鍵字篩選。
5. 點選「儲存」。

**注意：**存檔後就不能改問題本身。要換問題，請刪除後重新新增。

## 設了負責人之後會怎樣

- 這個問題在新主機上出現時，夜間會自動掛進負責人的交辦單。
- 寄通知信時，改寄給問題負責人，不再寄給主機負責人。
- 負責人可以檢視保留期間內出現過這個問題的所有主機，即使不在他的群組授權內。
- 在「問題查詢」的「依問題」視角，問題名稱旁會顯示「負責人」徽章。

## 常用操作：設定機房結論

機房結論是替整個機房的這個問題一次下結論，不用逐台標記。

1. 在列表點選該問題的「編輯」。
2. 在「機房結論」區塊選結論：已處理、不處理、誤報或已知雜訊。
3. 填寫原因（必填）。
4. 要讓之後新出現的日子也自動結案，勾選「之後新出現的主機日也自動套用這個結論」。
5. 點選「儲存」。

情況改變時點選「解除結論」，之後就不再自動套用。已經寫入的結案紀錄會保留。

## 常用操作：靜音一個問題

靜音讓問題暫時從清單、待辦與派工中消失，到期自動回來。

1. 在列表點選「靜音」。
2. 選時長：1 天、1 週、1 個月、3 個月、6 個月或自訂（最長 365 天）。
3. 填寫原因（必填）。
4. 這個問題有進行中的交辦單時，選「暫停，到期自動恢復」或「代為結案為『不處理』」。
5. 送出。

靜音中的問題會顯示「靜音至」日期，可以「延長」或「解除」。
頁面下方列出最近 10 筆靜音操作，以及留存的靜音區間。
靜音、告警抑制、統一標記怎麼選，見「讓告警安靜的工具」。

## 注意事項

- 刪除問題設定後，這個問題的通知與派工會回到主機負責人，機房結論也一起移除。
- 解除靜音只影響之後的日子；靜音期間已有結論的日子維持不變。
