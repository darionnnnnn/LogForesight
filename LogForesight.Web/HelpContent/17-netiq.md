# NetIQ 維護

NetIQ Sentinel 是收集機房主機日誌的平台，本系統從它取得大多數主機的資料。
這頁設定要連哪些 Sentinel、怎麼查詢，以及批次加入主機。
入口是「系統管理 > NetIQ 維護」，需要系統維護權限。頁面有「設定」、「匯入」、「診斷」三個分頁。

## 常用操作：加入一台 Sentinel

1. 在「設定」分頁點選「新增 Sentinel」。
2. 填「名稱」與「連線位址」（例如 https://sentinel.corp.local）。
3. 填「探索帳號」與「探索密碼」，批次匯入主機時會用到。密碼欄留空代表不變更。
4. 選「作業系統」（Windows 或 Linux），匯入時會當作預設值。
5. 點選「測試連線」，成功後「儲存」。

**注意：**刪除 Sentinel 後，它底下使用中的主機會被停用。歷史紀錄保留，之後可在主機頁改綁到其他 Sentinel。
只想暫時不查詢時，用「停用」，主機保持原狀。

## 常用操作：從網段批次加入主機

1. 切到「匯入」分頁，選一台已設好探索帳密的 Sentinel。
2. 輸入網段，例如 `192.168.0` 或 `192.168.0.0/24`。
3. 網段事件很多時，「掃描粒度」可改選「每段 62 台（最細）」，避免沒什麼事件的主機被漏掉；「併發」維持「單一查詢（預設）」即可。
4. 點選「掃描匯入」。
5. 勾選主機：點選「全選新主機」會勾新主機與可恢復的主機；已在使用中的主機預設不勾。
6. 點選「下一步」，確認作業系統、主機分級，替每個網段選主機群組（或建立新群組）。
7. 點選「完成匯入」。

只會找到最近有送出事件的主機。一直沒有事件的主機，請到主機頁手動加入。

## 查詢參數

這些設定套用到所有 Sentinel，平常用預設值即可：

| 欄位 | 說明 |
|---|---|
| 節流間隔（毫秒） | 每次查詢之間等多久；0 代表不等 |
| 單頁筆數／單一查詢最多筆數 | 每次查詢取幾筆；超過上限會截斷 |
| 逾時秒數／失敗重試次數 | 查詢多久沒回應算失敗、失敗重試幾次 |
| 每次執行回望天數 | 每次往回檢查幾天內有沒有漏掉的日子；上限依資料保留天數，畫面會顯示 |
| 同時處理幾台 Sentinel／單台 Sentinel 內查詢平行度 | 同時查詢的數量，上限分別是 3 與 4 |
| 略過憑證驗證 | Sentinel 使用公司自行簽發的憑證時才勾 |
| 詢問 AI 即時查詢現場事件 | AI 有設定時可開；查不到暫存資料時，向 Sentinel 即時查詢 |

## 診斷

不影響夜間排程，用來確認 Sentinel 連線與資料格式是否正常：

1. 在「診斷」分頁選 Sentinel。
2. 需要時填「樣本 IP（Windows，選填）」與「樣本 IP（Linux，選填）」。
3. 點選「執行診斷」，結果出現後可「複製」給維護人員。

「執行安全欄位探測」只看最近一小時的少量事件，檢查欄位名稱與格式，不讀取帳密、IP 或事件內容。結果只用來核對格式，不代表資料已可使用。
