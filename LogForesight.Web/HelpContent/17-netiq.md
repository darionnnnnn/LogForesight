# NetIQ 維護

NetIQ Sentinel 是收集機房主機日誌的平台，本系統從它取得大多數主機的資料。
這頁設定要連哪些 Sentinel、怎麼查詢，以及批次加入主機。
入口是「系統管理 > NetIQ 維護」，需要系統維護權限。頁面有「設定」、「匯入」、「診斷」三個分頁。

## 常用操作：加入一台 Sentinel

1. 在「設定」分頁點選「新增 Sentinel」。
2. 填「名稱」與「連線位址」（例如 https://sentinel.corp.local）。
3. 填「探索帳號」與「探索密碼」，批次匯入主機時會用到。密碼欄留空代表不變更。
4. 選「作業系統」（Windows 或 Linux），匯入時會當作預設值。
5. 要掃出沒有事件的已註冊主機時，勾「以 ESM 事件來源目錄探索」。
   帳號要有 ESM 唯讀權限。
6. 點選「測試連線」，結果會顯示在視窗內；成功後「儲存」。

**注意：**刪除 Sentinel 後，它底下使用中的主機會被停用。歷史紀錄保留，之後可在主機頁改綁到其他 Sentinel。
只想暫時不查詢時，用「停用」，主機保持原狀。

## 常用操作：從網段批次加入主機

1. 切到「匯入」分頁，選一台已設好探索帳密的 Sentinel。
2. 輸入網段，例如 `192.168.0` 或 `192.168.0.0/24`。
3. 網段事件很多時，在「掃描匯入」左邊的下拉選單選「每段 62 台（最細）」。
   這樣安靜的主機才不會被漏掉。
   再右邊的下拉選單是同時查幾個查詢，預設「單一查詢」。選「同時 2 個查詢」或「同時 3 個查詢」，會同時對這台 Sentinel 開多條查詢。只掃單一網段時沒有作用。
4. 點選「掃描匯入」。
5. 勾選主機：點選「全選新主機」會勾新主機與標「可復活」的主機。已在使用中的主機預設不勾。
6. 點選「下一步」，確認「作業系統」與「分級」，替每個網段選群組，或選「＋ 建立新群組…」。
7. 點選「完成匯入」。

只會找到最近有送出事件的主機。一直沒有事件的主機，請到主機頁手動加入。

## 查詢參數

這些設定套用到所有 Sentinel，平常用預設值即可：

| 欄位 | 說明 |
|---|---|
| 節流間隔（毫秒） | 每次查詢之間等多久；0 代表不等 |
| 單頁筆數／單一查詢最多筆數 | 每次查詢取幾筆；超過上限會截斷 |
| 逾時秒數／失敗重試次數 | 查詢多久沒回應算失敗、失敗重試幾次 |
| 每次執行回望天數 | 每次往回檢查幾天內有沒有漏掉的日子；上限依資料保留天數，畫面會顯示 |
| 同時處理幾台 Sentinel／單台 Sentinel 內查詢平行度 | 同時查詢的數量，上限分別是 3 與 4 |
| 略過憑證驗證 | 沒填信任指紋時才有作用。勾了會接受任何憑證，健康頁會提醒；建議改填下一欄 |
| 信任的憑證指紋（SHA-256） | Sentinel 使用公司自行簽發的憑證時填。只接受指紋相同的憑證，套用到所有 Sentinel |
| 詢問 AI 查無暫存資料時，向 Sentinel 即時查詢現場事件（僅 NetIQ 主機） | AI 有設定時可開 |
| 使用離線示範資料 | 只在非正式環境出現。開啟後，掃描匯入改用固定的假資料，不連 Sentinel。不要當成真實掃描 |

## 憑證指紋

指紋是憑證的識別碼。填了指紋，系統只連那張憑證的伺服器。

取得與填入：

1. 在 Sentinel 清單那一列點選「編輯」，再點選「測試連線」。
2. 結果下方會顯示「伺服器出示的憑證指紋」。
3. 請 Sentinel 管理者核對指紋，確認是自己的伺服器。
4. 在「連線與節流參數」把指紋貼到「信任的憑證指紋」，儲存。

Sentinel 換了憑證，指紋會跟著變，連線會失敗。
失敗訊息會寫「指紋不符」並附上新的指紋，核對後照上面步驟重貼。

不想每次換憑證都重貼：請把簽發憑證的 CA 裝進執行本系統的主機。
裝好後兩欄都留空、不勾，系統會照一般方式驗證憑證。

## 診斷

不影響夜間排程，用來確認 Sentinel 連線與資料格式是否正常：

1. 在「診斷」分頁選 Sentinel。
2. 需要時填「樣本 IP（Windows，選填）」與「樣本 IP（Linux，選填）」。
3. 點選「執行診斷」，結果出現後可「複製」給維護人員。

「執行安全欄位探測」只看最近一小時的少量事件，檢查欄位名稱與格式。
它不讀取帳密、IP 或事件內容。結果只用來核對格式，不代表資料已可使用。

## 常見狀況

- Sentinel 清單的「探索帳密」欄寫紅色「密碼無法解密」。代表儲存的密碼和目前的金鑰檔對不起來。點選「編輯」，重新輸入密碼並儲存。
- 編輯視窗的密碼欄下方會寫「已儲存的密碼無法解密（金鑰檔與資料庫不相符），請重新輸入。」
- 重新輸入之前，夜間分析會略過這台 Sentinel，底下的主機這趟不查詢，並算成失敗。重新輸入後，之後的排程會補查。
- 「診斷」分頁的 Sentinel 名稱後面寫「（密碼無法解密）」時，同樣先重新輸入密碼。
- 「匯入」分頁的選單仍可能選到這台，按「掃描匯入」才會出現「密碼無法解密」的錯誤。請先重新輸入密碼。
