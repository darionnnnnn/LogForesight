# 規則維護

規則決定「哪些事件算是危險訊號」。這頁用來新增、修改、停用規則。
入口是「系統管理 > 規則維護」，需要系統維護權限。

頁面有四個分頁：「Windows規則」、「Linux規則」、「PRTG規則」、「告警抑制」。
PRTG 規則的說明見「PRTG 維護」；告警抑制見「告警抑制」。

## 常用操作：新增一條規則

1. 切到要加規則的分頁（Windows 或 Linux）。
2. 點選「新增規則」。
3. 填規則 Id，必須以 `custom-` 開頭。
4. 填類別、嚴重度與比對條件。Windows 填來源與 Event ID；Linux 填程式名稱與訊息內容。
5. 確定這種事件一出現就很危險時，勾「命中即列為高風險日（重大）」。
6. 填說明欄位：「白話說明」、「不處理的影響」、「常見原因」、「處置步驟」。這些會顯示在風險日詳情。
7. 點選「先驗證」，沒有警告再儲存。

想從內建規則改一條自己的版本，在那條規則點選「以此為範本建立自訂規則」，就不用從頭填。

## 常用操作：修改內建規則

**注意：**不要直接改內建規則，更新時可能被蓋回去。

1. 把那條內建規則「停用」。
2. 點選「以此為範本建立自訂規則」。
3. 修改這條自訂規則並儲存。

改壞的內建規則可以點選「回復預設」還原，畫面會先列出前後對照。

## 看懂清單

- 清單順序就是比對順序：由上往下，第一條命中的規則生效。新規則會排在最後。
- 「已修改」徽章：這條內建規則被改過。
- 可依類別、嚴重度、內建／自訂、啟用狀態、有無抑制篩選。
- 有抑制設定的規則會顯示抑制筆數。

## 停用、遮蔽、抑制的差別

| 動作 | 關掉什麼 | 事件還會被記錄嗎 |
|---|---|---|
| 停用規則 | 這條規則的分類與說明 | 會，變成「其他」類別 |
| 遮蔽 | 不是你設的：前面有更廣的規則把它擋住，它永遠不會命中 | 會，被前面那條規則分類 |
| 告警抑制 | 通知與風險升級 | 會，畫面照常列出 |

驗證或儲存時發現遮蔽，系統會直接警告。Linux 規則要注意程式名稱的包含關係，例如「sudo」包含「su」：較精確的規則要排在前面。

## 內建規則更新

系統更新後，頁面上方會出現「內建規則有更新（vX → vY）」：

1. 點選「預覽差異」，看會新增、更新哪些規則。
2. 要連同你改過的內建規則一起更新，才勾「連同已修改的內建規則一併覆蓋」。不勾就只新增缺少的規則。
3. 確認後點選「套用」。

你的自訂規則不會被更新動到。

## 注意事項

- 規則變更只影響之後的分析；已經寫入的紀錄不會改變。要重算過去的日子，到「排程作業」用「立即執行」的重新分析模式。
- 只有自訂規則可以刪除，刪除後無法復原，這條規則的抑制設定也會一起刪除。
