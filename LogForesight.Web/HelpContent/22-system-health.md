# 系統健康

這頁讓維護人員快速確認系統是否正常運作。
位置在「系統管理 > 設定」的「系統健康」頁籤。

## 看懂六張卡片

| 卡片 | 看什麼 |
|---|---|
| PRTG 快照 | PRTG 最近的快照取得順不順；點卡內連結前往「PRTG 維護」檢查 |
| 排程資料新鮮度 | 排程有沒有啟用、最近一次成功更新資料是什麼時候；狀態為「正常」、「過期」，或確認靜音後的「已確認，靜音至（日期）」 |
| 慢查詢 | 最近最慢的資料庫操作 |
| 背景工作 | AI、回填、同步等背景工作的狀態，以及「密碼欄位加密」的金鑰來源 |
| 登入暫停 | 因多次登入失敗被暫時擋下的帳號與 IP，可手動解除；站台重新啟動後會清空 |
| 初始設定 | 首次啟動精靈與必要設定是否完成 |

## 常用操作：資料顯示「過期」時

1. 先看告示上寫的原因。寫「有憑證無法解密」時，到告示上的連結重新輸入密碼。
2. 到「系統 > 排程作業」看最近一次執行有沒有成功。
3. 確認站台服務還在執行（請管理員檢查 IIS 應用程式集區）。
4. 問題修好後，用「立即執行」跑一次完整範圍。成功後告示就會消失，不必等到夜間排程。
5. 原因已處理或暫時可接受時，點選「確認並靜音」，設定「靜音到」日期。

## 注意事項

- 只補本機或指定主機的手動執行不算資料更新，告示不會消失。
- 重新輸入全部密碼後，健康頁的「部分憑證無法解密」會馬上解除。
- 顯示「金鑰與資料庫不相符」時，還要重新啟動站台才會解除。已停用的 Sentinel 也要重新輸入密碼，用不到的可以刪除。
- 「密碼欄位加密」寫「金鑰檔與部署目錄在一起」時，代表重新部署會清掉金鑰檔。這時所有已存的密碼都會失效。
- 請管理員把金鑰檔改放到部署資料夾之外。或重新部署時，保留存放金鑰的資料夾。
- 已經這樣做的，可以忽略這句。
- 這句提示不會讓系統狀態變成異常，只是提醒。
- 「確認並靜音」只是暫時不再提醒，不會修復資料；這個動作會留下稽核紀錄。
- 排程剛跑完時，新鮮度最多晚 30 秒才更新。
- 郵件「寄送中」或「結果不確定」的項目不會自動釋放，避免重複寄信。
- 這頁不會把外部系統查詢失敗當成正常。要確認 PRTG 的連線與資料，請到「PRTG 維護」的「環境探測」。
