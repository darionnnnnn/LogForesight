# 系統健康

「系統健康」在「系統管理 > 設定」的同名頁籤，供維護人員檢查排程、背景工作、登入保護與初始化狀態。

## 排程資料新鮮度

「排程資料新鮮度」會顯示排程是否啟用、最近一次成功更新資料的時間，以及目前是「正常」或「過期」。過期時先檢查 IIS 應用程式集區、服務狀態與「排程作業」頁；確認暫時可接受後才按「確認並靜音」，並設定「靜音到」日期。

## 其他卡片

- 「慢查詢」：查看近期最慢的資料庫操作。
- 「背景工作」：查看 AI、回填、同步與其他背景工作狀態。
- 「登入暫停」：查看登入節流或暫停狀態。
- 「初始設定」：確認首次啟動精靈與必要設定是否完成。

系統健康頁是診斷入口，不會把外部系統查詢失敗解讀成資料正常；要確認 PRTG 的 API、鏡像與取數範圍，請到「PRTG 維護」的「環境探測」查看。
