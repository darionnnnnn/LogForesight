# 系統健康

這頁讓維護人員快速確認系統是否正常運作。
位置在「系統管理 > 設定」的「系統健康」頁籤。

## 看懂五張卡片

| 卡片 | 看什麼 |
|---|---|
| 排程資料新鮮度 | 排程有沒有啟用、最近一次成功更新資料是什麼時候；狀態為「正常」或「過期」 |
| 慢查詢 | 最近最慢的資料庫操作 |
| 背景工作 | AI、回填、同步等背景工作的狀態 |
| 登入暫停 | 因多次登入失敗被暫時擋下的帳號與 IP，可手動解除；站台重新啟動後會清空 |
| 初始設定 | 首次啟動精靈與必要設定是否完成 |

## 常用操作：資料顯示「過期」時

1. 到「系統 > 排程作業」看最近一次執行有沒有成功。
2. 確認站台服務還在執行（請管理員檢查 IIS 應用程式集區）。
3. 原因已處理或暫時可接受時，點選「確認並靜音」，設定「靜音到」日期。

## 注意事項

- 「確認並靜音」只是暫時不再提醒，不會修復資料；這個動作會留下稽核紀錄。
- 這頁不會把外部系統查詢失敗當成正常。要確認 PRTG 的連線與資料，請到「PRTG 維護」的「環境探測」。
