# 報表

報表給主管與資安團隊看全站整體的風險、趨勢與處理進度。
側欄位置是「監控作業 > 報表」。圖表上的數字都能點，點兩下內就能看到對應的問題清單。

## 常用操作

1. 選期間：自訂起訖日（最長 366 天），或用快捷鈕。快捷鈕的最後一天是昨天。
2. 選比較方式：「對比前一期」或「對比去年同期」。
3. 選「顯示範圍」：全部、未結案、未處理、未指派。
4. 點圖表或數字，打開對應的問題清單。

- 「自訂圖表」可選要顯示哪些圖，選擇會記在這台電腦的瀏覽器。
- 「列印 / 存成 PDF」會隱藏工具列，只留報表內容。
- 「查同一問題的其他主機」會帶你到問題查詢的「依問題」角度。

## 看懂上方四張卡

| 卡片 | 意思 |
|---|---|
| 問題總數 | 期間內發現的問題總數（含低風險日） |
| 高風險日 | 被判為高風險的主機日數 |
| 受影響主機 | 至少有一天是高或中風險的主機，同一台只算一次 |
| 涵蓋率缺口天數 | 資料不完整、應該有卻沒有的主機日數 |

卡片下方的徽章是跟比較期間的差異：

- 紅色向上：變多，代表變壞。
- 綠色向下：變少，代表改善。
- 灰色：持平。

## 看懂六張圖

| 圖 | 看什麼 |
|---|---|
| 告警數量趨勢 | 每天高、中風險主機日的變化 |
| 風險類型分布 | 各類別（儲存裝置、硬體、安全、服務、備份、設定、資源、其他）的問題數 |
| 主機／問題排行 | 右上角切換：問題最多的前 10 台主機，或最該優先看的前 10 個問題 |
| 風險層級占比 | 高、中風險日各占多少 |
| 受影響主機占比 | 受影響的主機占全部主機的比例 |
| 處理進度 | 高、中風險日已結案的比例 |

每張圖都能切換成表格檢視。

## 注意事項

- 查詢 180 天以上、且資料保留期夠長時，預設是「對比去年同期」。
- 去年同期超出保留期時，選項會標「（超出保留期）」，比較結果僅供參考。
- 「風險類型分布」不受「顯示範圍」影響。
- 「處理進度」只在顯示範圍為「全部」時出現。
- 問題排行不列全部主機都已有結論的問題，副標題會寫排除了幾個。
