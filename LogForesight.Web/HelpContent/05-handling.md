# 處理狀態、交辦單與案件

每個問題都可以標記處理狀態。
同一個問題出現在很多台主機時，用「交辦單」一次派給一位處理人，處理人也一次回覆。

## 看懂處理狀態

畫面上只有三種狀態：「未處理」、「處理中」、「已處理」。

| 結案時選的原因 | 什麼時候用 |
|---|---|
| 已處理 | 問題修好了 |
| 不處理 | 評估後決定不處理，必須寫原因 |
| 誤報 | 規則判斷錯了，其實沒事 |
| 已知雜訊 | 已知且無害的訊號 |

「無法處理」是處理中的一種，不是結案。
處理人自己解決不了時（例如要等廠商），選它並寫原因。
郵件通知開啟時，系統會寄信給 admin 群組，請他們改派或代為結案。

## 看懂交辦單

一張交辦單＝一個問題 × 一批主機 × 一位處理人。
單上的每一台主機叫做一個「成員」。

| 單的狀態 | 意思 |
|---|---|
| 進行中 | 還有主機沒結案 |
| 已結案 | 全部主機都結案 |
| 上報中 | 有主機被標為「無法處理」 |
| 暫停 | 這個問題正在靜音 |
| 未回覆 | 處理人還沒回覆過 |

同一個人、同一個問題，同時只會有一張進行中的單。再交辦同一個問題給他，主機會併進那張單。

## 處理人：回覆交辦單

1. 從側欄「我的交辦」打開自己的工作頁。
2. 點一列展開，勾選這次實際處理好的主機。
3. 點選「回覆」，選狀態並寫處理說明，送出。

- 勾選多張單可以一次回覆。
- 在問題查詢「依問題」視角點選「回覆處理狀態」，可回覆自己名下這個問題的全部單。
- 只能回覆自己是處理人的單。要替別人結案，請管理者用「代為結案」。
- 在風險日詳情逐筆標記也算回覆。

完整步驟見「我的交辦：三分鐘上手」。

## 管理者：交辦一個問題

1. 到「問題查詢」，切到「依問題」視角。
2. 用篩選列選好期間、主機或主機群組。
3. 在該問題那一列點選「交辦」。
4. 選一位使用者，或一個使用者群組（「平均輪流」或「依現有負載」分配）。
5. 看預覽：將交辦幾台、預估幾個主機日、已知雜訊排除幾台、誰已在處理。
6. 確認後送出。「交辦單通知」開啟時，處理人會收到信。

- 篩選選了主機，範圍就是那些主機；選了群組，就是那些群組；都沒選就是全站。
- 範圍不是指定主機時，可以勾「續掛新主機」：之後同範圍新出現此問題的主機，夜間自動加進這張單。
- 主機很多時，儀表板數字要幾分鐘後才會更新。

## 管理者：交辦總覽

側欄「交辦總覽」有四個頁籤：

| 頁籤 | 用途 |
|---|---|
| 進行中 | 全部交辦單；勾「只看自靜音恢復」可找出剛結束靜音的單 |
| 負載看板 | 每位處理人手上的單數、台數、未回覆、逾期 |
| 待派 | 有問題卻沒人處理；點選「立即派工」依自動派工規則建單 |
| 靜音中 | 正在靜音的問題，可延長或解除 |

點單號打開交辦單詳情，可以「複製 CSV」、改派、拆出主機、取消交辦、代為結案。
派錯人時用「取消交辦」：單上寫出去的處理中日子回到未處理，處理人自己標過的不動。

## 自動派工

- 設了問題負責人的問題，之後每晚新出現的主機會自動掛進負責人的單。
- 設定頁開啟自動派工後，沒人接手的新問題會派給「派工池」群組裡、看得到該主機、手上工作最少的人。
- 使用者頁可以把某人設為「暫停接單」（例如休假），就不會再派新單給他。
- 派不出去的問題會出現在「待派」頁籤。

以下情況不會自動派工：問題靜音中、命中告警抑制、標過已知雜訊、嚴重度不列入未處理計算、上次被標為不處理或誤報。

## 案件與跨日問題

每個成員背後是一個「案件」：一台主機的一個問題，跨好幾天也只有一件。

- 建案時，同一個問題還沒結案的舊日子會一起掛進來。
- 之後每天再出現，會自動掛進同一個案件，不必每天重標。
- 在任一天標記狀態，其他天會一起更新。
- 結案後問題又出現，會開一個新案件。

風險日詳情的問題列會顯示處理人、狀態與交辦單號，點單號可打開交辦單。

## 注意事項：交辦給看不到該主機的人

被交辦的人即使平時看不到那台主機，也能檢視被交辦的那個問題。
他看不到同一天的其他問題，頁面會標示「您以交辦單處理人身分檢視」。
案件授與不會附帶主機級的 PRTG 資訊，也不會多給任何管理權限。
