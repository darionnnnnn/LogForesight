# 處理狀態、交辦單與案件

風險日與其中的個別問題都可以標記處理狀態；同一個問題落在很多台主機時，用**交辦單**一次派給處理人、一次回覆。

## 處理狀態

對外一律呈現三態：**未處理**／**處理中**／**已處理**。「已處理」底下實際細分四種結案原因：已解決、不予處理、誤報、已知雜訊——結案時選擇最貼近實際情況的原因，方便日後追溯「當初為什麼判定不用處理」。

「處理中」底下還有一個**無法處理**：處理人評估後發現自己解決不了（例如需要外部廠商、超出自己的權限），標記時必須填寫原因。這**不是結案**——畫面上仍歸「處理中」，但會即時寄信通知全部 admin 群組成員（郵件通知已啟用時），請他們決定是要代為結案還是改派。

## 交辦單是什麼

一張交辦單＝**一個問題 × 一批主機 × 一位處理人**。單上的每一台主機叫做一個**成員**（背後是那台主機那個問題的案件）。

- 同一個人同一個問題同時只會有一張進行中的單；再交辦給他同一個問題時，主機會併進原本那張單。
- 單的狀態由成員推導：還有成員沒結案就是**進行中**；全部結案就是**已結案**；有成員「無法處理」就是**上報中**；問題正在靜音就是**暫停**；處理人還沒回覆過就是**未回覆**。
- 單上會記錄來源：人工交辦、負責人規則、自動派工、日層級指派、系統整併（升級時把舊案件整理成單）。

## 交辦一個問題（admin）

1. 問題查詢切到「依問題」，先用篩選列選好期間、主機或主機群組。
2. 在問題那一列按「交辦」。
3. 選交辦給一位使用者，或一個使用者群組（平均輪流或依現有負載分攤，一人一張單）。
4. 預覽會列出影響台數、預估主機日、已知雜訊排除的台數、已由別人處理中的主機（可勾選改派），以及會併進哪張既有的單。展開主機清單可以逐台取消勾選。
5. 範圍跟著篩選走：選了主機＝指定主機；選了主機群組＝那些群組；都沒選＝全站。範圍不是指定主機時可以勾「續掛新主機」：之後這個範圍內新出現此問題、還沒有人處理的主機，夜間自動加進這張單。手動取消勾選過主機時不提供續掛。
6. 送出後處理人會收到通知信（「交辦單通知」開啟時）。主機很多時逐日同步在背景完成，儀表板數字會在幾分鐘內更新。

依問題視角的「已交辦」欄顯示這個問題有幾台已在進行中的交辦單內；點處理人姓名直接看「這個問題、這個人」的單。

## 回覆（處理人）

- 側欄「我的交辦」是自己的工作頁，預設列出自己的進行中交辦單，KPI 顯示進行中單、進行中台數、逾期台數、未回覆單。
- 點一列展開成員，可以勾選部分主機回覆（例如 96 台裡 91 台已處理、5 台待換零件）。
- 勾選多張單可以一次回覆；也可以在問題查詢的「依問題」視角按「回覆處理狀態」，回覆自己名下這個問題的全部單。
- 只能回覆自己是處理人的單；要替別人結案請管理者用「代為結案」。
- 在風險日詳情逐筆標記也算回覆，未回覆的提醒會跟著消失。

## 交辦總覽（admin 與主管）

側欄「交辦總覽」有四個頁籤：

| 頁籤 | 用途 |
|---|---|
| 進行中 | 全部交辦單，可依狀態、處理人所屬群組篩選；「只看自靜音恢復」找出靜音剛結束的單 |
| 負載看板 | 每位處理人手上的單數、台數、未回覆、逾期、近 7 天結案 |
| 待派 | 期間內出現、卻沒有人處理的問題，附建議處理人與派不出去的原因；「立即派工」依自動派工規則一次建單（需要系統維護能力） |
| 靜音中 | 目前靜音中的問題與到期日，可延長或解除（需要系統維護能力） |

點單號進交辦單詳情：成員表（可複製 CSV）、時間軸，以及改派、拆出主機、取消交辦、代為結案。取消交辦用在派錯人：成員案件關閉，由單寫出去的處理中日子回到未處理，處理人自己標過的日子不動。

## 自動派工與問題負責人

- 設了**問題負責人**（「問題檔案」頁）的問題，之後每晚新出現的主機會掛進負責人的交辦單。多位負責人時交給手上工作最少的人。
- 系統設定開啟**自動派工**後，沒有負責人、也沒有續掛單接手的新問題，會派給**派工池**群組裡看得到該主機、手上工作最少的人；同一台主機同一個問題上次由誰修好，優先再交給他。
- 以下情況不派工：問題靜音中、命中告警抑制、該主機該問題標過已知雜訊、嚴重度不在「列入未處理計算」的等級、這台主機這個問題上次被標為不處理或誤報（不再打擾）。
- 使用者頁可以把某人設為「暫停接單」（例如休假），自動派工就不會再派新單給他，既有的單不受影響。
- 派不出去的問題會出現在交辦總覽的「待派」頁籤。

## 跨日問題案件

交辦單的每個成員背後是一個案件（一台主機 × 一個問題）：

- 建案時回溯歷史裡同一個問題所有未結案的日子，一併掛進案件。
- 之後每天新分析到同一個問題，會自動把新的一天掛進進行中的案件，不需要每天重新標記。
- 在案件涵蓋的任一天標記狀態，會同步展開到其他天。標成結案類狀態時案件結案，問題之後重新出現會是新的案件。
- 同一台主機同一個問題同時只歸一人處理；要換人請用改派。

風險日詳情頁的問題列上會看到案件徽章（處理人與狀態）與交辦單號，點單號進交辦單詳情。

## 案件授與：交辦給主機授權範圍外的人

被交辦的主機即使原本看不到，也會取得**針對那個問題**的檢視權。這個授與很窄：只看得到被交辦的問題，看不到同一天其他問題與整日的 AI 總覽；頁面會標示「您以案件處理人身分檢視」。結案後仍看得到自己處理過的紀錄。
