# 處理狀態與交辦單

每個問題都可以標記處理狀態。
同一個問題出現在很多台主機時，用「交辦單」一次派給一位處理人，處理人也一次回覆。

## 看懂處理狀態

問題的處理狀態有八種。未結案的四種是「未處理」、「處理中」、「觀察中」、「無法處理」。
結案的四種見下表。
「觀察中」：先看幾天再決定，到期沒處理視同逾期。在風險日詳情要填「觀察天數」，在「我的交辦」要填「預計完成日／觀察至」。
在「我的交辦」回覆時，可點「3 日」、「7 日」、「14 日」快速填日期，預設 7 日。
沒有勾選問題、只改整天的狀態時，沒有「觀察中」。

| 結案時選的原因 | 什麼時候用 |
|---|---|
| 已處理 | 問題修好了 |
| 不處理 | 評估後決定不處理，必須寫原因 |
| 誤報 | 規則判斷錯了，其實沒事 |
| 已知雜訊 | 已知且無害的訊號 |

「無法處理」不是結案，單的狀態會變成「上報中」。
處理人自己解決不了時（例如要等廠商），選它並寫原因。
郵件通知開啟時，系統會寄信給 admin 群組，請他們改派、退回或代為結案。
管理者在交辦單詳情點選「退回處理人」，並寫退回說明，這些主機就改回處理中。

## 看懂交辦單

一張交辦單＝一個問題 × 一批主機 × 一位處理人。
單上的每一台主機叫做一個「成員」。

| 單的狀態 | 意思 |
|---|---|
| 進行中 | 還有主機沒結案 |
| 已結案 | 全部主機都結案 |
| 上報中 | 有主機被標為「無法處理」 |
| 暫停 | 這個問題正在靜音 |
| 未回覆 | 處理人還沒回覆過 |

同一個人、同一個問題，同時只會有一張進行中的單。再交辦同一個問題給他，主機會併進那張單。

交辦單上的「台」是不重複的主機數。「件」是一台主機的一個問題。
同一台主機結案後又出現，會多一件，所以件數可能大於台數。
畫面寫「進行中 N 台；歷來 M 台、K 件」。

夜間自動派出的新單，會依嚴重度帶預設期限：高 3 天、中 7 天。
按「立即派工」建出的新單也一樣。
夜間續掛進舊單的新主機，若舊單的期限已過，期限改從續掛當天算起。
上線前就有的單沒有期限，不會因此變成逾期。

## 看懂復發與觀察到期

- 同一台主機的同一個問題，30 天內已處理結案又出現，標「復發」。
- 復發不會重開舊單。它是新的一件，掛進進行中的單或開新單。
- 詳情頁的「成員」卡片在狀態旁寫「復發 N 次」與上一次的回覆。
- 狀態篩選選「全部」時，同一台主機的舊件標「第 N 次」。
- 觀察中的主機寫「觀察期間再發生 N 天」、「沒有再發生」或「無資料」。
- 「無資料」是觀察期間沒有分析紀錄，不代表沒有再發生。
- 交辦單詳情最上方的「把到期且沒有再發生的 N 台結案」，一次結案觀察期滿的主機。
- 系統不會自動結案。
- 同一台主機同一個問題，30 天內第 3 次復發，管理員會在提醒區看到。

## 處理人：回覆交辦單

1. 從側欄「我的交辦」打開自己的工作頁。
2. 點一張單的「回覆」。回覆表單一定會打開，對象預設是全部進行中主機。
3. 只處理好其中幾台時，點「只回覆部分主機」。勾選主機，或貼上多個主機名，貼上後會自動勾選。
4. 選「這次的結論」並寫處理說明，送出。結論不會預選，沒選就不能送出。

- 只回覆部分主機並選結案狀態時，結論下方可選「其餘 N 台一起設為…」。選了，一次送出兩部分。
- 回覆含復發主機時，表單頂端寫「其中 N 台是反覆發生的問題。結案後又出現，建議先看原因：」。
- 下面有三顆建議鈕，前兩顆是「還在處理（設預計完成日）」、「觀察 7 日」。
- 勾選多張單可以一次回覆。
- 在問題查詢「依問題」視角點選「回覆處理狀態」，可回覆自己名下這個問題的全部單。
- 只能回覆自己是處理人的單。要替別人結案，請管理者用「代為結案」。
- 在風險日詳情逐筆標記也算回覆。
- 選「不處理（評估後決定）」、「誤報」或「已知雜訊」時，表單會多一行提醒。
- 提醒寫「這台主機的這個問題之後不會再派給任何人；需要恢復請找管理者」。
- 嚴重度高或重大的問題，提醒改寫成「30 天內不再派工，之後仍在發生會重新派工」。

完整步驟見「我的交辦：三分鐘上手」。

## 在風險日詳情標記處理狀態

點右側的「處理狀態」展開面板。面板由上而下分四塊：

1. 目前狀態：幾項已結案、最後更新時間，逾期時多一個「逾期」。
2. 人員：主機負責人與處理人。
3. 表單：先選狀態，需要時填預計完成日，再寫說明。勾選了問題時，最上方會寫「已勾選 N 個問題」。
4. 最下方的「儲存」或「套用到 N 個問題」。

## 說明欄的三個輔助工具

說明欄下方的灰色列有三個工具，帶入後仍要逐字確認：

- 「常用語」：選一句常用的說明帶入。
- 「沿用此問題上次的說明」：只勾一個問題時出現，帶入這個問題上次的處理說明。
- 「AI 整理」：把你寫的內容整理成條列，不會補上你沒寫的事。不滿意可按「復原」。

## 管理者：交辦一個問題

1. 到「問題查詢」，切到「依問題」視角。
2. 用篩選列選好期間、主機或主機群組。
3. 在該問題那一列點選「交辦」（列上沒有時，點「更多」找）。
4. 選一位使用者，或一個使用者群組（「平均輪流」或「依現有負載」分配）。
5. 看預覽：將交辦幾台、預估幾個主機日、已知雜訊排除幾台、誰已在處理。
6. 確認後送出。「交辦單通知」開啟時，處理人會收到信。

- 預覽的主機表格，狀態欄寫每台主機現在的處理狀態。
- 已結案與「先前判定不處理」的主機，預設不勾選，會被略過。
- 要重新交辦，請逐台勾選。勾選「先前判定不處理」的主機，等於恢復它。
- 表頭的全選只作用在這一頁的一般主機。
- 預覽會寫「已結案略過 N 台」與「先前判定不處理略過 N 台」。
- 預覽寫「N 台不在對方的檢視範圍」時，對方仍可經由交辦看到被交辦的問題。
- 選處理人時，名單寫每人的進行中台數，沒有 email 的標「沒有 email」。
- 「預計完成日（選填）」依嚴重度預填：高 3 天、中 7 天。可以改，也可以清掉。
- 篩選選了主機，範圍就是那些主機；選了群組，就是那些群組；都沒選就是全站。
- 範圍不是指定主機時，可以勾「續掛新主機」：之後同範圍新出現此問題的主機，夜間自動加進這張單。
- 主機很多時，儀表板數字要幾分鐘後才會更新。

## 管理者：交辦總覽

側欄「交辦總覽」有四個頁籤：

| 頁籤 | 用途 |
|---|---|
| 進行中 | 全部交辦單，可用「處理人」篩選，也能勾選多張「改派給…」；有嚴重度欄，問題下方標「新」、「復發」、「退回」、「觀察到期」；排序可選處理優先序、期限最近、嚴重度；勾「只看自靜音恢復」可找出剛結束靜音的單，勾「只看處理人已停用或失去處理能力」可找出處理人已接不了的單 |
| 負載看板 | 每位處理人手上的單數、台數、未回覆、逾期。數字含「問題靜音中而暫停」的單。點人名只看他的單，「改派他名下的單…」一次改派 |
| 待派 | 有問題卻沒人處理，分「可以派」、「派不出去」、「不會派」三段。已被處理人結案的主機不會列在這裡。下方有「不再自動派工」區 |
| 靜音中 | 正在靜音的問題，可延長或解除 |

只有系統管理員能用「立即派工」，也只有系統管理員看得到「靜音中」頁籤。主管與開發人員能檢視交辦總覽，但不能改。
點單號打開交辦單詳情。改派、取消交辦、代為結案在頁面最上方卡片的右側。
「成員」卡片上方可以「複製 CSV」、拆出主機。

- 「成員」卡片的「主機名」欄位，輸入完整主機名後按 Enter，只看那一台。
- 勾選的主機換頁或搜尋後仍保留，卡片上寫「已選 N 台」。改變狀態篩選才會清掉勾選。
- 整單結案後，狀態篩選會自動切到「全部」，讓你看到已結案的主機。你自己再選回「進行中」，就不會再被切走。
派錯人時用「取消交辦」：單上寫出去的處理中日子回到未處理，處理人自己標過的不動。

## 管理者：待派頁的三段

「待派」頁籤把近 7 天沒人接的問題分成三段：

| 段落 | 意思 |
|---|---|
| 可以派 | 找得到處理人。預設展開，列出建議處理人與台數 |
| 派不出去 | 找不到處理人。依原因分組，每組只說明一次 |
| 不會派 | 嚴重度未達、不再打擾、抑制、已知雜訊或靜音。預設收合 |

儀表板的「待派工問題」只算前兩段。
「派不出去」的原因有三種：沒有派工池成員、候選人全部暫停接單、派工池成員都看不到這些主機。

1. 要派單，點整頁的「立即派工」，或點某個問題那一列的「派這個問題」。
2. 先看預覽：將建立幾張單、併入幾張單、共幾台，以及派不出去的原因。
3. 確認後才會建單。「派這個問題」只派那一個問題。

- 別人剛派完時，會寫「沒有需要派的項目（可能剛由其他人派出）」。
- 「沒有人看得到」的主機群組，每個群組只出現一次。
- 有維護權限的人，點群組旁的「授權給…」選一個派工池群組，就能就地補授權。
- 沒有維護權限時，看不到授權選單，畫面會請你洽系統管理員。

## 管理者：一次改派多張單

1. 在「交辦總覽」的「進行中」頁籤，勾選要改派的單。
2. 點「改派給…」，選新處理人，點「預覽」。
3. 預覽逐張寫改派方式：「原單換處理人」或「併入 #單號」，以及要補上授與的台數。
4. 確認無誤後點「確定改派 N 張」，結果會逐張列出。

- 一次最多 100 張。超過時按鈕停用，請取消部分勾選。
- 新處理人暫停接單、沒有 email 或沒有處理能力時，預覽會提醒。仍可改派。
- 某一張失敗不影響其他張，失敗的原因寫在結果表。
- 在負載看板點「改派他名下的單…」，會自動篩出那位處理人並勾好他的單。
- 停用帳號或勾「暫停接單」前，若他名下還有進行中的單，畫面會先問要不要「一併改派」。

## 管理者：代為結案

1. 在交辦單詳情最上方卡片右側，點選「代為結案」。
2. 「結案狀態」一開始是「請選擇結案狀態」，要自己選一次。
3. 選「不處理」、「誤報」或「已知雜訊」時，下方多一個勾選框，預設不勾。
4. 勾選框寫「這台主機的這個問題之後不再自動派工」。單上有多台進行中主機時，寫「這 N 台主機」。單上不只一種問題時，改寫「這台主機上的問題」或「這 N 台主機上的問題」。
5. 填「結案原因（必填）」，點選「代為結案 N 台」。

- 「結案範圍」可選「全部進行中」、「只有上報中的」或「勾選的成員」。單上有上報中的主機時，預設是「只有上報中的」。
- 只結案部分主機時，單上其餘主機繼續進行。
- 勾選：問題之後再出現，不會再派給任何人。資料保留期過了不會失效，時間到了也不會自動恢復。要恢復，到待派頁的「不再自動派工」區。
- 不勾選：問題再出現時會重新派工。畫面寫「不想再收到，請勾選上方選項，或改用靜音」。
- 選「已處理」沒有勾選框。修好又壞是新的狀況，會重新派工。
- 開啟「交辦單通知」時，處理人會收到結案通知。信裡寫結案狀態、原因，以及問題再出現時會不會重新派工。
- 沒開啟時，對話框寫「目前未啟用交辦單通知，請自行告知處理人」。

## 管理者：不再自動派工區

在「交辦總覽」的「待派」頁籤下方，列出被停止自動派工的問題。區塊預設收合，標題旁寫「共 N 個問題、M 台」，展開才載入清單。

1. 區內依問題分組，每組寫問題名稱與台數。
2. 每台主機一列，有「先前結案狀態」、「結案的人」與「日期」。
3. 恢復單一主機，點該列的「恢復」。
4. 恢復整個問題，點該組的「整個問題恢復」。
5. 確認後，下一次夜間派工會重新判斷要不要派。

- 每一列的「恢復派工」欄寫何時自動恢復：「N 天後恢復派工」、「永久」或「上線前判定」。
- 處理人判定不處理的高嚴重度或重大問題，結案滿 30 天後，仍在發生就會重新派工。中、低嚴重度是永久。
- 管理者代為結案時勾選的，也是永久。
- 上線前就結案的高嚴重度問題標「上線前判定」，不會自動恢復，要自己點「恢復」。
- 恢復只拿掉「不再自動派工」，不建單，結案狀態維持不變。
- 只有系統管理員看得到「恢復」鈕。主管與開發人員只能看清單。
- 沒有被停止的問題時，區內寫「沒有不再自動派工的問題」。

## 管理者：交辦單上的狀況標記

| 標記 | 出現在哪裡 | 意思 |
|---|---|---|
| 續掛已停止：原因 | 詳情頁首、總覽「進行中」 | 夜間派工不再把新主機加進這張單 |
| 主機已停用 | 詳情「成員」卡片、總覽「成員」欄 | 主機停用，不計入處理人的台數 |
| 復發 N 次 | 詳情「成員」卡片 | 這台主機的這個問題，30 天內結案後又出現 |
| 觀察期間再發生 N 天 | 詳情「成員」卡片 | 觀察中的主機，觀察期間又出現了幾天 |
| 第 N 次 | 詳情「成員」卡片 | 同一台主機的第幾件，只在「全部」篩選出現 |
| 處理人目前看不到 N 台 | 詳情頁首 | 這些主機不在處理人平常看得到的範圍 |
| 先前判定不處理 | 詳情「成員」卡片 | 上一件被判定不處理，滿 30 天仍在發生才重新派工 |

- 「處理人目前看不到 N 台」與「續掛已停止」是寫給管理者看的，處理人本人看交辦單時不會出現。
- 續掛停止的原因有三種：處理人已停用或失去處理能力、處理人暫停接單、處理人看不到新主機。
- 處理人恢復資格後，新出現的主機照常續掛，標記就消失。
- 處理人看不到的主機，他仍可處理被交辦的那個問題。
- 在「使用者」頁停用帳號或勾「暫停接單」時，若他名下還有進行中的交辦單，畫面會提醒張數。
- 提醒附「到交辦總覽改派或結案」的連結。這些單不會自動轉走。

## 通知與管理者提醒

開啟「交辦單通知」後，處理人依「交辦摘要時刻」收到一封彙整信。信裡的段落有：

- 新交辦、新增成員、移交、取消、退回。
- 代為結案：管理者替你結案了。
- 靜音暫停：這個問題被靜音，單暫停處理，到期自動恢復。
- 靜音恢復：靜音提前解除，請繼續處理。

- 退回段附「只看被退回的單」連結，點了直接只看被退回的單；其他段的連結打開你的「我的交辦」。

- 改派或拆出主機時，接手的人若已有同問題的進行中單，主機併進那張單，對方收到「新增成員」。
- 收件人是操作者本人時不寄。

管理者提醒寄給 admin 群組裡有 email 的成員，隨交辦摘要寄出：

- 上報（無法處理）超過 N 天還沒人處理的成員。
- 最近一次夜間派工派不出去的問題。
- 上報時沒有收件人的單。
- 反覆結案又復發的成員：同一台主機同一個問題，30 天內復發達 3 次。

- N 是設定頁「管理者提醒間隔（天）」，預設 3。同一個成員每隔 N 天最多提醒一次。
- 填 0 就不寄信。要寄信，也要開啟「啟用郵件通知」與「交辦單通知」。
- 「交辦總覽」頁籤上方的提醒區顯示這四項，另有「今天新上報」，讓你當天就看到剛上報的主機。
- 系統管理員另會看到：最近一趟取數失敗、可派未派、處理人已停用或暫停仍有單、未分組主機。
- 這幾項同時出現在儀表板最上方的「需要你處理」一列。可派未派不會寄信。
- 「今天新上報」不寄信。提醒區不受郵件開關影響，各項都是 0 時不顯示。
- 每一項可點選「看是哪些」展開明細。上報的明細列出單號，點了開啟那張單。

## 自動派工

- 設了問題負責人的問題，之後每晚新出現的主機會自動掛進負責人的單。
- 設定頁開啟自動派工後，沒人接手的新問題會自動派出。
- 自動派工選「派工池」群組裡、看得到該主機的人。
- 選人的優先順序有三層。
- 第一，這一趟已經派過這個問題的人。
- 第二，最近 30 天內修好過同一台主機同一個問題的人。
- 第三，手上工作最少的人。
- 使用者頁可以把某人設為「暫停接單」（例如休假），就不會再派新單給他。
- 派不出去的問題會出現在「待派」頁籤。

滿 30 天重新派工的新單，成員旁會標「先前判定不處理」，並寫日期與判定人。
處理人再次回覆不處理，就重新計 30 天。

以下情況不會自動派工：

- 問題靜音中，或命中告警抑制。
- 標過已知雜訊，或上次被標為不處理、誤報。嚴重度高或重大的，滿 30 天後會重新派工。
- 上一條的例外：管理者代為結案時沒勾「不再自動派工」，問題再出現就會重新派工。
- 嚴重度不列入未處理計算。

## 交辦單頁上的處置參考與捷徑

- 單頭的「處置參考」寫影響、可能原因與處置步驟。「訊息樣本」列最近一次出現的幾則訊息。兩者都能就地展開。
- 沒有對應規則的問題沒有處置參考。
- 「這個問題的其他交辦單」打開已篩選的交辦總覽。
- 有維護權限的人另有「靜音這個問題」、「不再顯示這個問題…」與「調整這條規則」。
- 同一台主機有多列時，每列會寫登錄類型，例如 System。
- 沒有權限檢視這張單時，不會顯示成員與處理歷程。

## 成員與跨日問題

每個成員是一台主機的一個問題，跨好幾天也只有一個成員。

- 建單時，同一個問題還沒結案的舊日子會一起掛進來。
- 之後每天再出現，會自動掛進同一個成員，不必每天重標。
- 在任一天標記狀態，其他天會一起更新。
- 結案後問題又出現，會算成新的成員，掛進該問題進行中的交辦單或開一張新單。

風險日詳情的問題列會顯示處理人、狀態與交辦單號，點單號可打開交辦單。

## 注意事項：交辦給看不到該主機的人

被交辦的人即使平時看不到那台主機，也能檢視被交辦的那個問題。
他看不到同一天的其他問題，頁面會標示「您以交辦單處理人身分檢視」。
交辦授與不會附帶主機級的 PRTG 資訊，也不會多給任何管理權限。
