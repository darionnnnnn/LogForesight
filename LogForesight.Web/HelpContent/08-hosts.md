# 主機與群組

主機清單決定系統要分析哪些主機；群組決定誰看得到哪些主機。
入口是「系統管理 > 主機」與「系統管理 > 群組與授權」，需要系統維護權限。

## 常用操作：加入主機

| 方法 | 適合 | 在哪裡 |
|---|---|---|
| 從 NetIQ 匯入 | 一次加入整個網段的主機 | 主機頁的「從 NetIQ 匯入」，見「NetIQ 維護」 |
| 批次貼上 | 已有清單，一次貼上多台 NetIQ 主機 | 主機頁的「批次貼上」 |
| 新增主機 | 加一台 | 主機頁的「新增主機」 |

**注意：**主機的作業系統（「OS」欄）決定套用 Windows 或 Linux 規則。設錯會整台檢查錯。

## 常用操作：一次設定多台

1. 在主機清單勾選要設定的主機。
2. 點選「批次設定群組」、「批次設定分級」或「指派負責人」。
3. 設定群組時選「加入」（保留原有群組）或「取代」（只留勾選的群組）。

## 看懂主機清單

| 欄位或標記 | 意思 |
|---|---|
| OS | Windows 或 Linux |
| 分級 | 核心、一般、測試；只影響問題的優先順序，不影響檢查 |
| 負責人 | 他不用加入群組也能看到並處理這台主機 |
| 停用（不分析） | 這台不再分析，舊紀錄保留 |
| IP 衝突 | 有好幾台用同一個 IP；只有最早建立的那台會被查詢 |
| 待歸屬 Sentinel | 還不知道該從哪台 Sentinel 取資料 |
| 未分組 | 還沒加入任何主機群組，只有 admin 看得到 |
| 已併入其他主機 | 這筆已合併到另一台主機 |

## 群組與授權

「群組與授權」頁有三個分頁：

| 分頁 | 用途 |
|---|---|
| 使用者群組 | 依部門或團隊分組使用者 |
| 主機群組 | 依機房或用途分組主機；也是告警抑制的範圍選項 |
| 授權矩陣 | 勾選「哪個使用者群組看得到哪個主機群組」 |

授權矩陣只列一般使用者群組。Admin、Manager、Dev 本來就看得到全部主機。

## 常見狀況

- 主機出現「IP 衝突」：確認是否重複登錄，停用多餘的那筆。
- 某台主機沒有資料：確認它沒有「停用（不分析）」或「待歸屬 Sentinel」標記。
- 新加的主機看不到分析結果：要等下一次排程執行後才會有。
