# 儀表板

儀表板一眼看出全站（或你看得到的主機）最近的風險狀況。多數人登入後先進這頁。只負責處理交辦的人會先進「我的交辦」。開發維運會先進「排程作業」。
側欄位置是「監控作業 > 總覽儀表板」。

## 先看哪裡

1. 左上角選期間：「昨日」、「近 7 天」或「近 30 天」。
2. 看上方一排數字卡，紅色或數字大的先看。
3. 看「重點問題」：最值得優先處理的前 5 個問題。
4. 點卡片或問題，會帶著條件打開對應的頁面（問題查詢、主機、稽核紀錄等）。「監控主機數」與「涵蓋率缺口天數」只是數字，不能點。

**注意：**期間的最後一天是「昨天」，不是今天。夜間分析只會算到昨天。

## 需要你處理

有指派權限的人，儀表板最上方多一列「需要你處理」。
只列數字不是 0 的項目，每一項點了就到處理的地方：

- 最近一趟取數失敗、今天新上報、上報逾期。
- 可派未派、派不出去、上報沒有收件人。
- 處理人已停用或暫停、仍有單。
- 反覆復發、未分組主機。

全部都是 0 時，這一列收成「目前沒有需要你處理的項目」。
主管與開發人員沒有這一列。

## 看懂數字卡

| 卡片 | 意思 |
|---|---|
| 高風險日／中風險日 | 期間內被判為高、中風險的主機日數 |
| 監控主機數 | 你看得到的主機數 |
| 涵蓋率缺口天數 | 應該有資料卻沒有的天數 |
| 未處理問題 | 還沒處理的問題數；有逾期時會標出。下方寫「影響 N 台．風險日未處理 X、處理中 Y」，影響台數與點進去的問題查詢一致 |
| 我的交辦單 | 你手上進行中的交辦單（有處理權限才會出現） |
| 待派工問題 | 近 7 天沒人接的問題，不受上方期間影響。數字是「可以派」加「派不出去」，下方分開寫；嚴重度未達、不再打擾的不算。已被處理人結案的主機也不算（有指派權限才會出現） |
| 未回報主機 | 最後一次送資料超過 2 天的主機；新加入、從未送過資料的主機，過 24 小時才算。能管理主機的人點卡片進主機頁；其他人不能點，卡片下方會直接列出未回報的主機名（最多 5 台） |
| 權限異動待確認 | 待核對的帳號權限變更。沒有待確認的就整張卡不出現（有確認權限才會出現） |
| 24 小時登入失敗 | 最近一天登入失敗的次數。點進去的明細含昨天全日，所以筆數可能比卡片多 |

數字旁的「資料最近更新」顯示資料有多新。過期時請聯絡管理員。

## 看懂「重點問題」

重點問題依「分數」排序，不是單純看次數。
分數綜合六件事：嚴重度、影響台數、是否擴散、多新、未處理多少、主機重要程度。
滑鼠移到分數上，可看到每一項的加權。

| 欄位 | 意思 |
|---|---|
| vs 基準 | 這次影響台數 ÷ 平常的台數 |
| 本期首見 | 在這次查詢期間內第一次出現的日子 |
| 首見（機房） | 整個機房第一次出現的日子 |
| 變化 | 跟前一期比主機數的增減：「↑N%」變多、「↓N%」變少、「持平」、「本期新增」；「—」表示前期沒有可比的資料 |

## 看懂「vs 基準」

「vs 基準」的顏色：

- 紅色「擴散」：2 倍以上，影響範圍異常變大，優先看。
- 灰色「正常」：1～2 倍，一般波動。
- 綠色「收斂」：低於 1 倍，情況正在好轉。
- 「新問題，無基準」：過去 30 天內出現不到 3 天，還無法比較。

全部主機都已有結論的問題不列入，卡片底部會寫「另有 N 個問題已有結論（未列入）」。
被靜音的問題也不列入，卡片底部會寫「另有 N 個問題靜音中（未列入）」。

## 看懂「風險類型」

依問題類別（儲存裝置、硬體、安全、服務、備份、設定、資源、其他）分卡，最嚴重的排在前面。

畫面只先顯示一排。要看其餘類別，按「風險類型」卡標題右側的「顯示其餘 N 類」。
按鈕上寫「M 項告警」時，表示收起來的卡裡有紅色警示的項目，例如重大問題、逾期或未回報主機。上方的數字卡也一樣，按鈕是「顯示其餘 N 項指標」。

每張卡三行：

- 「N 個問題」：有幾種不同的問題。
- 「M 台主機」：受影響的主機，同一台只算一次。
- 「期間累計 K 筆」：出現的主機日總數，數字大代表拖得久。

點卡片會打開問題查詢。列表每一列的主機數加起來會比卡片多，因為同一台主機會出現在好幾列。要對照卡片，看列表上方的「共 N 台主機（去重）」。

## 其他卡片

- 「高風險主機」：期間內風險最高的主機。
- 「依群組風險概況」：各主機群組的風險分布，點一列可看該群組的問題。
- 「AI 今日焦點」：AI 挑出最該優先看的幾項。AI 沒設定或失敗時不會出現，不影響其他數字。短時間內反覆切換天數會讓 AI 暫停約一分鐘，卡片會寫「AI 暫時休息，約 N 秒後再試」。

## 常見狀況

- 風險日沒有 AI 摘要：標題會寫當天最重的問題名稱與說明，不會是空白。
- AI 剛連不上時，約一分鐘內 AI 功能暫時不出現，今日焦點也不顯示。其他數字不受影響。
- 點進去的筆數跟卡片不一樣：同一台主機會出現在好幾列，逐列加總就會比較大。
- 「未回報主機」卡點不開：你沒有管理主機的權限。卡片下方會列出你看得到的未回報主機，最多 5 台。
- 畫面很安靜：只代表「已經分析過的」主機沒事。沒被掃到的主機不會出現在這裡，請看「未回報主機」卡與風險日詳情的「資料涵蓋率」。
- 顏色在全站意思都一樣：紅＝高、黃＝中、灰＝低。「系統管理 > 設定」的「日風險等級顯示」只影響看不看得到，不會改變已判定的風險等級。
