# 儀表板

儀表板是登入後的第一頁，一眼看出全站（或你看得到的主機）最近的風險狀況。
側欄位置是「監控作業 > 總覽儀表板」。

## 先看哪裡

1. 左上角選期間：「昨日」、「近 7 天」或「近 30 天」。
2. 看上方一排數字卡，紅色或數字大的先看。
3. 看「重點問題」：最值得優先處理的前 5 個問題。
4. 點任何卡片或問題，會直接帶著條件打開問題查詢。

**注意：**期間的最後一天是「昨天」，不是今天。夜間分析只會算到昨天。

## 看懂數字卡

| 卡片 | 意思 |
|---|---|
| 高風險日／中風險日 | 期間內被判為高、中風險的主機日數 |
| 監控主機數 | 你看得到的主機數 |
| 涵蓋率缺口天數 | 應該有資料卻沒有的天數 |
| 未處理問題 | 還沒處理的問題數；有逾期時會標出 |
| 我的交辦單 | 你手上進行中的交辦單（有處理權限才會出現） |
| 待派工問題 | 沒人處理的問題（有指派權限才會出現） |
| 未回報主機 | 一段時間沒送資料來的主機 |
| 權限異動待確認 | 待核對的帳號權限變更（有確認權限才會出現） |
| 24 小時登入失敗 | 最近一天登入失敗的次數 |

數字旁的「資料最近更新」顯示資料有多新；過期時請聯絡管理員。

## 看懂「重點問題」

重點問題依「優先度分數」排序，不是單純看次數。
分數綜合六件事：嚴重度、影響台數、是否擴散、多新、未處理多少、主機重要程度。
滑鼠移到分數上，可看到每一項的加權。

| 欄位 | 意思 |
|---|---|
| vs 基準 | 這次影響台數 ÷ 平常的台數 |
| 本期首見 | 在這次查詢期間內第一次出現的日子 |
| 首見（機房） | 整個機房第一次出現的日子 |
| 變化 | 跟前一期比，主機數是增加、減少或持平 |

「vs 基準」的顏色：

- 紅色「擴散」：2 倍以上，影響範圍異常變大，優先看。
- 灰色「正常」：1～2 倍，一般波動。
- 綠色「收斂」：低於 1 倍，情況正在好轉。
- 「新問題，無基準」：出現不到 3 天，還無法比較。

全部主機都已有結論的問題不列入，卡片底部會寫「另有 N 個問題已有結論（未列入）」。

## 看懂「風險類型」

依問題類別（儲存裝置、硬體、安全、服務、備份、設定、資源、其他）分卡，每張卡三行：

- 「N 個問題」：有幾種不同的問題。
- 「M 台主機」：受影響的主機，同一台只算一次。
- 「期間累計 K 筆」：出現的主機日總數，數字大代表拖得久。

點卡片會打開問題查詢。列表每一列的主機數加起來會比卡片多，因為同一台主機會出現在好幾列。要對照卡片，看列表上方的「共 N 台主機（去重）」。

## 其他卡片

- 「高風險主機」：期間內風險最高的主機。
- 「依群組風險概況」：各主機群組的風險分布，點一列可看該群組的問題。
- 「AI 今日焦點」：AI 挑出最該優先看的幾項。AI 沒設定或失敗時不會出現，不影響其他數字。

## 常見狀況

- 點進去的筆數跟卡片不一樣：同一台主機會出現在好幾列，逐列加總就會比較大。
- 畫面很安靜：只代表「已經分析過的」主機沒事。沒被掃到的主機不會出現在這裡，請看「未回報主機」卡與風險日詳情的「資料涵蓋率」。
- 顏色在全站意思都一樣：紅＝高、黃＝中、灰＝低。設定頁的顯示選項只影響看不看得到，不會改變已判定的風險等級。
