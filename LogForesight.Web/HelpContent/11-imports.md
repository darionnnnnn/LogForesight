# 匯入

這頁用 CSV 檔一次指派很多台主機的負責人。
入口是「系統管理 > 資料匯入」，需要系統維護權限。

## 常用操作：匯入負責人

1. 點選「下載範本」，取得空白 CSV。
2. 用 Excel 填寫，每列一台主機、一位負責人。一台主機有多位負責人就寫多列。
3. 另存新檔時選「CSV UTF-8」，否則中文會變亂碼。
4. 上傳檔案，系統會先顯示預覽。
5. 確認預覽沒有錯誤，點選「套用」。

## 欄位怎麼填

| 欄位 | 怎麼填 |
|---|---|
| host_name | 主機名稱；與 ip_address 擇一填 |
| ip_address | 主機 IP；與 host_name 擇一填 |
| owner_account | 負責人帳號，必填；帳號不存在時會自動建立 |

畫面上的「欄位格式說明」有同樣的說明。

## 注意事項

- 檔案裡出現的主機，負責人會整組換成檔案裡的人，不是加上去。
- 只要有一列錯誤（例如找不到主機），整份檔案都不會套用，按鈕會顯示「有錯誤，無法套用」。請依預覽的行號修正後重新上傳。
- 系統不會自動建立主機，主機要先在主機頁存在。

## 其他資料在哪裡維護

- 主機：「NetIQ 維護」的匯入，或「主機」頁。
- 使用者：「使用者」頁，可一次新增多位。
- 群組授權：「群組與授權」頁的授權矩陣。

## 匯入紀錄

頁面下方的「匯入紀錄」列出歷次 CSV 匯入與 NetIQ 掃描匯入的結果。
