# 稽核日誌

「系統 > 操作紀錄」頁（`/audit`，需 ViewAudit 能力，admin 與 serverAdmin 角色具備）集中記錄系統內所有寫入類異動操作與身分安全性事件，提供完整的不可竄改稽核軌跡。

## 稽核紀錄的核心特性

- **僅記錄異動與身分事件**：系統只記錄新增、修改、刪除、指派、狀態變更、確認等寫入類操作，以及登入、登出、權限被拒等身分事件。不記錄日常的查詢與頁面瀏覽，避免日誌被流量淹沒。
- **Append-only 不可竄改**：稽核資料庫僅支援寫入與查詢，系統中沒有提供任何修改或刪除稽核紀錄的介面與 API。
- **敏感資料保護**：使用者密碼、探索密碼與 AI API 金鑰等敏感資訊，在寫入稽核紀錄時一律遮蔽或排除，絕不記入細節中。
- **即時生成白話摘要**：每筆紀錄在操作發生的當下即組好中文摘要句（例如「將 SRV-WEB01 2026-08-10 的處理人由 A 改為 B」），讓清單可直接一眼掃視。由系統內部自動執行的操作（如排程自動指派），帳號會標記為 `(system)`。

## 查詢與篩選條件

- **起始與結束日期**：預設為近 7 天（本地日期）。結束日期在查詢時會涵蓋至當天 23:59:59，確保當日產生的紀錄都能完整查出。
- **動作**：多選下拉選單，依後端動作代碼分類（包含登入/登出、處理狀態變更、統一標記、權限異動確認、規則維護、主機與群組管理、問題檔案維護、CSV/NetIQ 匯入、Sentinel 與設定調整、排程手動執行等）。
- **結果**：下拉選單提供「全部」、「成功」（`Ok`）、「被拒」（`Denied`）、「失敗」（`Failed`，如密碼錯誤）。
- **只看被拒的存取**：紅色快捷按鈕。點擊可一鍵快速過濾出所有權限不足被系統阻擋的操作嘗試（`Denied`），再次點擊可取消篩選切回全部。儀表板上的「登入失敗 / 存取被拒」卡片下鑽亦會自動同步至此篩選狀態。

## 紀錄清單與明細對照

- **清單欄位**：
  - **時間**：操作發生的日期時間，點擊表頭可切換新到舊（降冪，預設）或舊到新（升冪）排序。
  - **帳號**：執行操作者的 `顯示名稱(帳號)`。未知帳號或系統帳號則直接顯示帳號字串。
  - **動作**：動作的中文名稱。
  - **結果**：徽章呈現（白色「成功」、紅色「被拒」、黃色「失敗」）。
  - **內容**：操作的白話摘要句。若該筆操作包含欄位級前後對照，摘要右下方會提供「詳細」按鈕，點擊可展開 JSON 格式的變更前後差異（Before / After）。
  - **來源 IP**：發起該請求的客戶端 IP 位址。
- **分頁控制**：底部分頁列支援換頁與自訂每頁筆數（設定值會保存在瀏覽器中）。
