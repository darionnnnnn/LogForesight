# 稽核日誌

這頁記錄「誰在什麼時候做了什麼」，用來追查設定被誰改過、有沒有人試圖越權。
入口是「系統 > 稽核紀錄」，系統管理員與救援帳號看得到。

## 常用操作：查某人某天做了什麼

1. 選起始與結束日期（預設近 7 天）。
2. 在「動作」選要看的類別，例如登入、處理狀態變更、規則維護，可複選。
3. 需要時選「結果」：全部、成功、被拒、失敗。
4. 查詢後，點「詳細」可看某筆異動的前後差異。

想找有人越權嘗試的紀錄，點選「只看被拒的存取」，再點一次取消。
儀表板的「24 小時登入失敗」卡也會帶你到這裡。

## 看懂紀錄

| 欄位 | 意思 |
|---|---|
| 時間 | 發生時間，點表頭可切換排序 |
| 帳號 | 誰做的；系統自動執行的會寫 (system) |
| 動作 | 做了哪一類操作 |
| 結果 | 成功、被拒（沒有權限）、失敗（例如密碼錯誤） |
| 內容 | 一句話說明，例如「將 SRV-WEB01 的處理人由 A 改為 B」 |
| 來源 IP | 從哪台電腦送出的 |

## 注意事項

- 只記錄會改變資料的操作與登入、登出、被拒等事件；單純瀏覽與查詢不記錄。
- 紀錄只能新增，不能修改或刪除。
- 密碼與 API 金鑰不會寫進紀錄。
- 超過保留天數（預設 730 天）的紀錄會自動清除，天數在「系統管理 > 設定」的「資料保留」調整。
