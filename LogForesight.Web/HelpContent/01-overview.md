# 系統總覽與登入

LogForesight 每天讀取 Windows 與 Linux 主機的日誌。
它會提早找出硬碟快壞、被入侵等徵兆。
它會告訴你：哪台主機、哪一天、出了什麼問題、該怎麼處理。

## 系統怎麼判斷風險

1. 每晚收集前一天的日誌。
2. 用規則找出已知的危險訊號，例如磁碟錯誤、可疑登入。
3. 跟過去比較，看次數有沒有突然變多。
4. 檢查好幾種事件是否湊成可疑組合。
5. 依以上結果判定當天的風險：高、中、低。
6. 最後請 AI 把結論寫成白話。AI 認為更嚴重時，只能把風險往上調，不能往下壓。

**注意：**風險判斷主要由程式規則決定。AI 沒設定或故障時，系統照常判斷，只是少了白話摘要。

## 登入

- 用公司的網域（AD）帳號與密碼登入。
- 帳號或密碼錯誤時，登入頁會直接顯示錯誤訊息。
- 另有一組救援帳號，網域登入故障時讓管理員進來修設定。帳號名稱向系統管理員確認。
- 救援帳號只能維護設定與查稽核紀錄，看不到儀表板、問題查詢與報表。這是刻意的安全設計。
- 登入後超過 8 小時沒有操作，系統會自動登出，要重新登入。有操作就會順延。
- 就算一直在用，連續登入滿 24 小時也要重新登入。
- 離開時點選「登出」。登出後，你在其他電腦或瀏覽器的登入也會一起失效。
- 帳號被停用或被登出的人，下一次操作就會回到登入頁。

## 你看得到什麼

你看得到的功能由你所屬群組的角色決定：

| 角色 | 可以做什麼 |
|---|---|
| User（一般使用者） | 只看被授權的主機，可以處理交辦單 |
| Dev（開發人員） | 看全部主機（唯讀），可看排程執行狀態 |
| Manager（主管） | 看全部主機（唯讀） |
| Admin（系統管理員） | 全部功能 |

你是某台主機的負責人時，即使沒加入任何群組，也看得到那一整台主機，並能處理它的交辦單。
問題負責人也一樣，看得到保留期內出現過該問題的整台主機。
系統管理員可在「群組與授權」查看詳細設定。

## 從哪裡開始

- 處理人：從「我的交辦」開始，見「我的交辦：三分鐘上手」。
- 主管：從「總覽儀表板」看整體狀況。
- 管理員：第一次使用請先走「首次啟動精靈」。

分析由「系統 > 排程作業」每晚自動執行，也可以手動「立即執行」。第一次執行會自動補齊過去的資料。
