# 系統總覽與登入

LogForesight 每天讀取 Windows 與 Linux 主機的日誌。
它會提早找出硬碟快壞、被入侵等徵兆。
它會告訴你：哪台主機、哪一天、出了什麼問題、該怎麼處理。

## 系統怎麼判斷風險

1. 每晚收集前一天的日誌。
2. 用規則找出已知的危險訊號，例如磁碟錯誤、可疑登入。
3. 跟過去比較，看次數有沒有突然變多。
4. 檢查好幾種事件是否湊成可疑組合。
5. 依以上結果判定當天的風險：高、中、低。
6. 最後才請 AI 把結論寫成白話。

**注意：**風險判斷由程式規則決定，不靠 AI。AI 沒設定或故障時，系統照常判斷，只是少了白話摘要。

## 登入

- 用公司的網域（AD）帳號與密碼登入。
- 帳號或密碼錯誤時，登入頁會直接顯示錯誤訊息。
- 另有一組救援帳號，網域登入故障時讓管理員進來修設定。帳號名稱向系統管理員確認。
- 救援帳號只能維護設定與查稽核紀錄，看不到儀表板、問題查詢與報表。這是刻意的安全設計。

## 你看得到什麼

你看得到的功能由你所屬群組的角色決定：

| 角色 | 可以做什麼 |
|---|---|
| User（一般使用者） | 只看被授權的主機，可以處理交辦單 |
| Dev（開發人員） | 看全部主機（唯讀），可看排程執行狀態 |
| Manager（主管） | 看全部主機（唯讀） |
| Admin（系統管理員） | 全部功能 |

你是某台主機或某個問題的負責人時，即使沒加入任何群組，也看得到並能處理自己負責的部分。
詳見「授權與角色」。

## 從哪裡開始

- 處理人：從「我的交辦」開始，見「我的交辦：三分鐘上手」。
- 主管：從「總覽儀表板」看整體狀況。
- 管理員：第一次使用請先走「首次啟動精靈」。

分析由「系統 > 排程作業」每晚自動執行，也可以手動「立即執行」。第一次執行會自動補齊過去的資料。
