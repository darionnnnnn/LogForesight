# 告警抑制

某個訊號已確認是無害的雜訊，不想再被它吵，又不想整條規則停用時，用告警抑制。
抑制只關掉通知與風險升級，事件仍會照常記錄，之後隨時查得到。

## 常用操作：建立抑制

依你要擋的東西，從不同地方建立：

| 要擋什麼 | 從哪裡建立 | 範圍 |
|---|---|---|
| 整條規則 | 「規則維護」清單上那條規則的「抑制」按鈕 | 單一主機、主機群組或全站 |
| 次數突增 | 風險日詳情「頻率異常」旁的「抑制此類告警（本主機）」 | 單一主機 |
| 可疑組合 | 風險日詳情「關聯訊號」旁的「抑制此關聯模式」 | 單一主機 |
| 已知雜訊的問題 | 在風險日詳情把問題標為「已知雜訊」後，系統會詢問「一併建立抑制規則？」或「一併建立簽章抑制？」 | 單一主機 |

建立時：

1. 選範圍：「單一主機」、「主機群組」或「全站」（只有規則抑制可選群組與全站）。
2. 填「原因」（必填）。
3. 填「生效天數」，留空就是永久。選「全站」時預設帶入 30 天。
4. 選群組或全站時，系統會先顯示影響多少主機、過去 14 天命中幾次，確認後送出。

**注意：**主機群組範圍會跟著群組走，之後加入群組的主機也會被抑制。

## 看懂「告警抑制」分頁

「規則維護」的「告警抑制」分頁用來檢視與解除，不在這裡新增。

- 可依平台與目標篩選：規則、簽章、關聯模式、總量。
- 已到期的抑制會標「（已到期，告警已恢復）」，規則清單上的徽章會寫「抑制已到期」。
- 要提前結束，點選「解除」。

## 抑制與其他做法的差別

| 做法 | 關掉什麼 |
|---|---|
| 告警抑制 | 通知與風險升級；事件仍記錄、仍顯示在「已抑制的告警」區塊 |
| 停用規則 | 這條規則的分類與說明 |
| 靜音 | 整個機房暫時不看某個問題，到期自動恢復 |
| 已知雜訊（結案原因） | 單一個案的處理結果 |

怎麼選，見「讓告警安靜的工具」。

## 注意事項

- 抑制只影響設定之後的分析。過去的紀錄不會被改寫，要等下一次分析才看得到效果。
- 到期後設定不會自動刪除，只是恢復告警；分析輸出會寫「抑制已到期，恢復告警」。
- 刪除自訂規則時，它的抑制設定會一起刪除。
