# 權限異動檢核

這頁列出主機上的帳號權限變更，例如有人被加進系統管理員群組。
你要逐筆確認：這是公司授權的操作，還是可疑的？
入口是側欄「監控作業 > 權限異動檢核」，有確認權限的人才看得到。

## 常用操作：確認一筆異動

1. 在「待確認」頁籤找到那一筆。
2. 點那一列展開，看異動前後的內容與原始訊息。
3. 確認是授權操作，就標記為授權；有疑慮就標記為可疑。
4. 標記可疑時必須寫「說明」。

**注意：**確認之後不能改回「待確認」。送出前請看清楚。

## 常用操作：一次確認很多筆

1. 用上方篩選縮小範圍，例如選定一個類別或一段網段。
2. 勾選要處理的列；也可以點選「全選符合目前篩選的權限異動」。
3. 點選「標記為授權操作」或「標記為可疑」。
4. 確認視窗會依類別與主機分組列出你選的項目，核對後送出。

- 翻頁不會清除已勾選的項目。
- 選取數量有上限，超過時畫面會提示分批處理。
- 其中幾筆剛好被別人處理掉時，只略過那幾筆，其他照樣完成。

## 看懂畫面

| 位置 | 意思 |
|---|---|
| 四個頁籤 | 待確認、已確認授權、標記可疑、全部 |
| 異動說明 | 一句話：誰 → 做了什麼 → 對誰，例如「A 將 B 加入群組 C」 |
| 帳號 | 顯示短名；滑鼠停在上面可看完整名稱 |
| 高風險徽章 | 有人被加進 Administrators、Domain Admins 等特權群組 |
| 「—」 | 這個欄位抓不到資料，不是用猜的 |

每一筆會標示來源：

- 「本機監控」：比對本台主機前後狀態發現的變更。時間是發現的時間，不是實際發生的時間。
- 「NetIQ 事件」：從主機的安全日誌推算的變更。時間是事件發生的時間。

## 篩選方式

- 搜尋框：比對主機、帳號、對象、說明。
- 網段：例如 `192.168.1.0/24`、`192.168.1.*` 或單一 IP。
- 類別：可複選，例如群組成員異動、資料夾權限異動、稽核政策變更。
- 來源與時間範圍。

篩選條件會記在網址上，把網址傳給同事就能看到同一組結果。

## 常見狀況

- 看到一列「例行同步（彙總）」：同一天同一帳號在同一群組被加入又移出很多次（50 對以上），通常是自動同步程式造成，所以合併成一列。特權群組不會被合併。
- 異動前後顯示「（訊息未提供）」：原始事件裡就沒有這項資料。
- 類別是「其他」：系統還不認得這種異動，請回報管理員。
