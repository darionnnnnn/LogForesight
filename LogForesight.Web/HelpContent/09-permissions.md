# 授權與角色

授權回答兩個問題：你能用哪些功能，以及你看得到哪些主機。
兩件事分開設定，在「系統管理 > 使用者」與「系統管理 > 群組與授權」維護，需要系統維護權限。

## 角色：能用哪些功能

角色設定在使用者群組上：

| 角色 | 可以做什麼 |
|---|---|
| User（一般使用者） | 只看被授權的主機；處理交辦單；確認權限異動 |
| Dev（開發人員） | 看全部主機（唯讀）；看排程執行狀態 |
| Manager（主管） | 看全部主機（唯讀） |
| Admin（系統管理員） | 全部功能，包含指派、系統維護與稽核紀錄 |

一個人可以屬於好幾個群組，能用的功能是全部群組加起來。例如同時在 User 與 Dev 群組，就能處理交辦單，也能看全部主機。

## 可見範圍：看得到哪些主機

有四種方式讓人看得到一台主機：

| 方式 | 看得到什麼 | 在哪裡設定 |
|---|---|---|
| 群組授權 | 授權給他所屬群組的主機 | 「群組與授權」的授權矩陣 |
| 主機負責人 | 他負責的主機整台 | 「主機」頁或負責人 CSV 匯入 |
| 問題負責人 | 保留期內出現過該問題的主機整台 | 「問題負責與靜音」頁 |
| 交辦 | 只有被交辦的那個問題 | 交辦時自動取得 |

Admin、Manager、Dev 本來就看得到全部主機，不受授權矩陣限制。
主機負責人與問題負責人即使沒加入任何群組，也能處理交辦單與確認權限異動。

## 常用操作：讓新同事看得到主機

1. 到「系統管理 > 使用者」新增帳號，或確認帳號已存在。
2. 到「系統管理 > 群組與授權」，把他加進適合的使用者群組。
3. 在「授權矩陣」勾選這個使用者群組可以看的主機群組。

只負責少數主機時，也可以直接把他設為那些主機的負責人。

## 注意事項

- 一般使用者群組沒有勾授權矩陣，就看不到任何主機，畫面會寫「尚未被授權任何主機」。
- 通知信優先寄給問題負責人；沒有問題負責人時才寄給主機負責人。
- 救援帳號只能維護設定與查稽核紀錄，看不到業務資料。

權限異動的確認方式見「權限異動檢核」。
