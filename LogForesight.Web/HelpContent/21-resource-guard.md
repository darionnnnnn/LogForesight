# 資源守門

資源守門在「系統管理 > 設定 > 資源守門」，同時節制 NetIQ 與 PRTG 取數，預設關閉。啟用前可先按「預覽受監看 sensor」查看目前值，也可按「自動偵測並填入」把偵測到的 objid 寫入覆寫清單。

## 設定欄位

- 「CPU 門檻（%）」：CPU 值達門檻代表資源緊張。
- 「可用記憶體門檻（%）」：可用記憶體低於門檻代表資源緊張。
- 「檢查間隔（秒）」、「暫停檢查時間（分鐘）」、「連續超標次數」、「累計暫停上限（分鐘）」：控制檢查、暫停與單趟上限。
- 「受監看感測器覆寫清單（objid）」：每行一個 sensor objid；留白時由系統自動偵測。

按頁面底部「儲存」才會一起保存設定。PRTG 尚未同步或自動偵測沒有結果時，先到「PRTG 維護」同步結構與對應，或使用能在現場驗證過的覆寫清單。

## 執行時行為

連續超標達到設定次數後，取數會暫停，恢復後才繼續；單趟累計暫停達上限後會放行並留下警告。讀不到 sensor、即時查詢失敗或 API 不可用時，守門會放行並在執行資訊中說明，避免守門本身讓排程卡住。

資源守門只作用於夜間取數與 PRTG 逐顆取值。環境探測、歷史回填與 PRTG 快照有各自的執行規則。
