# 資源守門

資源守門會在 NetIQ 或 PRTG 主機忙不過來時，自動暫停夜間取數，等資源恢復再繼續，避免把監控系統拖垮。
設定在「系統管理 > 設定」的「資源守門」頁籤，預設關閉。

## 常用操作：啟用資源守門

1. 點選「預覽受監看 sensor」，看目前讀到的 CPU 與記憶體數值。
2. 點選「自動偵測並填入」，讓系統找出要監看的 PRTG 項目。
3. 確認門檻數值，勾「啟用資源守門」。
4. 點選頁面底部的「儲存」。

## 看懂設定

| 欄位 | 預設 | 意思 |
|---|---|---|
| CPU 門檻（%） | 85 | CPU 超過這個值算忙碌 |
| 可用記憶體門檻（%） | 10 | 可用記憶體低於這個值算忙碌 |
| 檢查間隔（秒） | 60 | 多久檢查一次 |
| 連續超標次數 | 2 | 連續忙碌幾次才暫停 |
| 暫停檢查時間（分鐘） | 5 | 每次暫停多久再檢查 |
| 累計暫停上限（分鐘） | 120 | 一趟最多累計暫停多久，超過就放行 |
| 受監看感測器覆寫清單（objid） | 空白 | 要監看的 PRTG 項目編號，一行一個；留空由系統自動偵測 |

## 常見狀況

- 「自動偵測並填入」找不到東西：先到「PRTG 維護」做「同步結構與對應」，再試一次。
- 執行輸出寫守門放行：讀不到數值、查詢失敗或累計暫停到上限時，守門會放行並留下說明，避免排程一直卡住。

## 注意事項

資源守門只管夜間取數：NetIQ 每批查詢前，以及 PRTG 每次查詢歷史數值與狀態變更前。
本機分析、歷史回填、環境探測與 PRTG 快照不受它控制。
