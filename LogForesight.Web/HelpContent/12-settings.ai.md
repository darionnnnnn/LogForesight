# 系統設定（AI 參考指引）

## 頁面基本資訊與存取架構

- **頁面路徑**：`/admin/settings`。
- **存取權限**：需要 `Maintain` 能力（`Capability.Maintain`，管理員角色可存取）。
- **後端端點**：
  - 讀取設定：`GET /api/admin/settings`，回傳 `SystemSettingsDto`（含目前設定與進階參數出廠預設值 `aiAdvancedDefaults`）。
  - 更新設定：`PUT /api/admin/settings`，傳入 `UpdateSystemSettingsRequest`，儲存後即時生效，無需重啟站台。
  - AD 測試連線：`POST /api/admin/settings/ad-test`，以當前表單數值與管理者輸入之帳密驗證連線（`TestAdConnection`）。
  - 測試寄信：`POST /api/admin/settings/mail-test`，以當前表單數值試寄測試信（`TestMail`）。
  - Token 用量查詢：`GET /api/admin/settings/ai-usage`，取得 Token 統計與近 30 天明細（`AiUsageDto`）。
  - Token 用量重設：`POST /api/admin/settings/ai-usage/reset`，清空 Token 統計並重設起算日為今日。

## 七大設定分頁（Panels）詳細規範

### 1. 層級與顯示（`data-panel="display"`）
- **問題嚴重度（`SeverityThresholds`）**：高／中／低三級核取方塊。控制哪些等級計入未處理統計，以及未勾選層級在前端預設隱藏或全站隱藏。
- **日風險等級顯示（`VisibleDayRisk`）**：控制全站（儀表板、報表、問題查詢）統計與列表是否顯示特定風險等級的主機日。
  - **重要原則**：此設定**僅影響顯示範圍，絕不改寫歷史判定結果**（判定結果是批次分析當下算出的不可篡改證據層）。
  - 「高風險日」為核心必要顯示項目，UI 強制鎖定無法取消勾選。

### 2. AI 服務（`data-panel="ai"`）
集中管理 AI 提供者、連線金鑰、進階推論參數與 Token 用量統計。

#### 提供者配置表
- **本機 OpenAI 相容端點（`Local`，預設）**：API 位址（如 `http://localhost:8080` 或 KoboldCpp 網址）、模型名稱（預設 `local-model`）、API 金鑰（選填）。
- **OpenAI 官方（`OpenAi`）**：API 金鑰（必填）、模型名稱（如 `gpt-4o-mini`）。API 位址為選填（留空使用官方端點，僅走 proxy 時填寫）。
- **Azure OpenAI（`AzureOpenAi`）**：端點位址、部署名稱（Deployment Name）、API 版本（預設 `2024-10-21`）、API 金鑰。模型由 Azure 端部署決定，無需另填。
- **資訊安全與金鑰加密**：切換至雲端提供者時，分析過程最多 500 則原始 log 訊息（可能包含帳號與內部 IP）會傳送至外部第三方。金鑰儲存於資料庫時會以加密保護；正式環境務必配置環境變數 `LF_CRYPTO_KEY`。
- **純統計模式降級**：若位址或必填金鑰留空，系統自動停用 AI 並降級為純統計模式——規則命中、趨勢比對與關聯分析照常執行，僅跳過 AI 推論，速度大幅提升。

#### 進階參數（`#ai-advanced` 折疊區）
出廠預設值源自 `SystemSettings` 後端初始值，平常無需調整。各欄位定義：
1. **單次呼叫逾時（`TimeoutSeconds`）**：範圍 1～3600 秒，出廠預設 1200 秒。因地端 27B 級大模型單次回應可能長達數分鐘，避免分析在即將完成時被中斷。
2. **網路層重試次數（`RetryCount`）**：範圍 1～10 次，出廠預設 3 次。因網路波動、HTTP 5xx 或連線中斷時的自動重試次數。
3. **首次重試等待（`RetryDelaySeconds`）**：範圍 0～300 秒，出廠預設 10 秒。重試時採用指數退避策略（例如 10s → 20s → 40s）。
4. **JSON 檢查未過重問次數（`JsonRetryCount`）**：範圍 0～10 次，出廠預設 2 次（不計入網路層重試）。當 AI 輸出無法解析為合法 JSON 或內容驗證失敗時的重問次數。重問時會將上一次的錯誤原因一併附給模型要求修正。
5. **一般呼叫 token 上限（`MaxTokens`）**：出廠預設 2048（0＝不設上限）。控制每日總覽、前置掃描這類終端摘要的最大 completion token 數。調大不會提高成功率——模型一旦退化成重複輸出，上限越大只是讓失敗的嘗試跑越久才觸頂。
6. **深入分析 token 上限（`DeepDiveMaxTokens`）**：出廠預設 8192。深入分析的輸出上限，與上一項分開的理由是它的篇幅天生比終端摘要長。
7. **頻率懲罰（`FrequencyPenalty`）**：範圍 0～2.0（步進 0.1），出廠預設 0.8。依據字詞在已產生文字中的出現頻率施加懲罰，抑制模型重覆跳針。
8. **存在懲罰（`PresencePenalty`）**：範圍 0～2.0（步進 0.1），出廠預設 0.8。促使模型引入新字詞與新概念，與頻率懲罰互補、一起抑制退化重複。
9. **額外請求欄位（`ExtraRequestFieldsJson`）**：字串（必須為合法 JSON 物件，如 `{"rep_pen": 1.3}`）。直接合併至傳送給推論伺服器的請求 Payload。留空表示不附加。
10. **還原預設值按鈕（`#btn-ai-advanced-reset`）**：點擊後僅將所有進階參數填入出廠預設值，**不會直接存檔**；使用者仍需點擊整頁底部的「儲存」按鈕方能生效。

#### Token 用量統計（`AiUsageStore`）
- **指標摘要**：
  - `今日消耗`：當日消耗之 total tokens 數。
  - `累計消耗`：自起算日（`countingSince`）以來的總 total tokens 數。
  - `累計呼叫次數`：累計發出的 AI 請求總次數。
- **計量母體**：在每次實體 HTTP POST 完成後立即計量，包含因回應格式錯誤或空回應而重試的每一次嘗試；命中快取而未真正送出者不計入。
- **未回報 Token 提示**：若部分地端模型未回傳 usage 欄位，呼叫次數照常計算、token 記為 0，畫面會顯示警告「注意：有 N 次呼叫的模型未回報 token 數」。
- **單價試算與估費**：
  - 欄位：`ai-input-price`（input 每百萬 token 單價）與 `ai-output-price`（output 每百萬 token 單價）。
  - 計算公式：`cost = (promptTokens * inputPrice + completionTokens * outputPrice) / 1,000,000`。
  - 幣別由使用者自行認定，數值為 0 時表示不估費。此功能僅為前端試算，不影響後端呼叫，單價隨整頁設定儲存。
- **清空重新計算（`#btn-ai-usage-reset`）**：彈出破壞性確認對話框，確認後呼叫 `POST /api/admin/settings/ai-usage/reset`，清除歷史每日與累計紀錄，並將起算日重設為今天（此操作不可復原）。
- **近 30 天明細表格（`#ai-usage-days-table`）**：以表格條列近 30 天每日的日期、呼叫次數、Prompt Tokens、Completion Tokens 與 Total Tokens。

#### AI 可信度與誠實申報原則
- 技術限制：地端模型無法可靠地進行句級自我歸因（強行標示只會產生看似精確實則幻覺的假引用）。
- 誠實落點：所有 AI 產出內容在 UI 上一律置於獨立區塊；若日風險等級係由 AI 判定上調，會在判定依據中明確標註「AI 上調」，清楚區隔程式確定性結果與 AI 推論。

### 3. AD 驗證（`data-panel="ad"`）
- 控制項：啟用開關、伺服器位址（Host）、連接埠（預設 389 或 LDAPS 636）、SSL 開關、搜尋基準（Base DN）、服務帳號（Bind DN）與密碼。
- **本機救援帳號（`serverAdmin`）不受 AD 開關與設定影響**，防止 AD 配置錯誤時管理員被鎖在系統外。
- 提供「測試連線」功能，使用管理者當前輸入的帳密即時驗證 LDAP 連線，無需預先存檔。

### 4. 分析參數（`data-panel="analysis"`）
- **伺服器角色描述（`ServerDescription`）**：補充說明伺服器之業務定位（例如「網域控制站」），此文字會注入 AI Prompt 輔助風險情境判讀。
- **體檢間隔天數（`CheckupIntervalDays`）**：定期體檢週期（1～365 天），採 Due-Date 輪巡推進。
- **額外監控權限異動資料夾（`WatchedFolders`）**：一行一個路徑，自動監控 Windows 目錄權限變更（站台目錄自動納入）。
- **要掃描的 Event Log 頻道（`AnalysisChannels`）**：自訂掃描頻道清單，留空使用預設六頻道。
- **CSV 匯入上限（`ImportBatchSize`）**：單次匯入筆數限制。
- **權限異動欄位對應（`PermissionFieldMappings`）**：當自訂日誌來源使用非標準欄位名稱時，自訂操作者、成員、群組、物件的欄位名稱映射。

### 5. 資料保留（`data-panel="retention"`）
- 保留項目：歷史分析紀錄（`RetentionDays`）、執行歷程日誌（`RunHistoryRetentionDays`）、稽核日誌（`AuditRetentionDays`）、風險 Log 暫存（`RiskLogRetentionDays`）。
- **90 天強制下限**：所有保留天數下限均為 90 天（上限 3650 天），防止因誤設過短導致歷史基準與對比失效。
- 清理機制：每次批次分析啟動時自動執行清除；單次清理上限 50,000 筆以避免鎖表，並於執行日誌申報剩餘待清筆數。

### 6. 郵件通知（`data-panel="mail"`）
- 控制項：啟用開關、SMTP 主機、連接埠、SSL/TLS、寄件人、密碼、收件人清單（一行一位）。
- **觸發時機**：
  1. 執行摘要信（批次分析結束後寄送）。
  2. 每日／每週定時彙總報表。
  3. 高風險日即時通知（同一主機同一日僅寄一次）。
  4. 上報即時信（問題被標記為「無法處理」時立即通知全體 admin 成員）。
- **郵件內容架構（問題優先）**：
  - 郵件內容按問題分為四大區塊：`逾期`、`新出現`、`擴散中`、`其他高風險`。
  - 高風險即時通知保留「主機日附錄」以利對照。
  - 行數截斷保護：摘要上限 50 行，即時信上限 20 行。
- **收件人權限過濾**：每位收件人僅能看見其授權範圍內的主機清單；若收件人為非系統帳號的共用信箱，僅呈現全站統計數字，不列出具體主機名稱。
- **連續失敗自動暫停**：某地址連續寄送失敗 3 次時，系統自動將其標記為暫停寄送，避免阻礙後續郵件佇列。

### 7. 外觀與品牌（`data-panel="branding"`）
- 主標題、副標題文字設定；品牌圖示（PNG/JPG，上限 64KB）上傳。
- 副標題自動對齊機制：字元短於主標題時自動撐開字距左右對齊，長於主標題時靠左對齊並以省略號截斷。

## 常見問答與邊界狀況（Q&A）

- **Q: 為什麼點擊了 AI 進階參數的「還原預設值」，重新整理頁面後又變回原樣？**
  - **A**: 「還原預設值」按鈕僅將設定頁面上的表單欄位填回出廠預設值，並未立即寫入資料庫。必須點擊頁面底部的「儲存」按鈕，新設定才會真正持久化生效。
- **Q: 為什麼 Token 用量統計顯示累計了呼叫次數，但 Token 數卻是 0？**
  - **A**: 部分地端推論伺服器（例如某些舊版 llama.cpp 或未啟用 usage 輸出的自建 API）在回應中未包含 Token 統計資訊。LogForesight 會照常記錄該次呼叫次數，但將 Token 記為 0，並於介面上提示未回報的呼叫次數。
- **Q: 估算金額的幣別是什麼？輸入單價會影響 AI 呼叫的額度嗎？**
  - **A**: 幣別由使用者自行定義（例如輸入美金單價試算即為美金，輸入新台幣單價即為新台幣）。單價輸入框純粹供管理者內部費用預估與統計對帳使用，絕不影響後端 AI 呼叫或連線行為。
- **Q: 為什麼在設定中將中風險日取消勾選後，報表上的中風險日都不見了，這會刪除資料嗎？**
  - **A**: 不會。「日風險等級顯示」僅控制前台視覺與統計報表的過濾範圍，歷史資料庫中判定之風險等級完整保留且不可篡改。重新勾選後即可立即恢復顯示。
