# 問題事件

「問題查詢」頁可以跨主機、跨日期找問題，不必先點進某台主機。
側欄位置是「監控作業 > 問題查詢」。

## 常用操作：找出某個問題

1. 在「主機」輸入名稱或 IP 搜尋，可選多台。不選就是全部。
2. 填「起始日期」與「結束日期」，或點右邊的快捷鈕，例如「近 7 天」。快捷鈕的最後一天是昨天。
3. 需要時點「更多條件」，填「Event ID」（事件編號）或「來源」，例如 `disk`。
4. 點選「套用」。要重來就點選「清除條件」。
5. 在「明細」角度點一列，打開那台主機那一天的「風險日詳情」。其他角度點列的結果不同，見下表。

表格上方還可以依風險層級、風險類型、處理狀態、主機群組再縮小範圍。
風險層級預設只選「高」「中」，低風險的列一開始不會出現。要看就點選「低」。
「依問題」角度的風險層級篩選叫「問題嚴重度」。

## 切換檢視角度

| 按鈕 | 每一列是 | 適合 |
|---|---|---|
| 依問題 | 一個問題，跨所有主機彙總；點列會就地展開受影響的主機，一台一列 | 找出影響最廣的問題、交辦、靜音 |
| 明細 | 一台主機的一天（一個風險日）；點列進入風險日詳情 | 逐筆追查 |
| 依主機 | 一台主機；點列進入那台主機的詳細頁 | 看哪台主機問題最多 |
| 依日期 | 一天；點列切到「明細」並只看那一天 | 看哪天特別嚴重 |

**注意：**在「依問題」角度，高／中／低篩的是「問題嚴重度」。
其他角度篩的是「風險層級」，也就是那一天的整體風險。畫面上的標籤會跟著變。

## 看懂「依問題」的欄位

問題名稱下方有一行白話說明。分類是「其他」代表沒有命中任何規則，可以到「規則維護」替它建規則。
問題有指派負責人時，名稱旁會出現「負責人」徽章。

| 欄位 | 意思 |
|---|---|
| 主機數 / 主機日 | 幾台主機出現過；總共幾個「主機×天」 |
| vs 基準 | 這次影響台數 ÷ 平常的台數，紅色「擴散」要優先看 |
| 首見 | 整個機房第一次出現的日子；本期第一次出現的日子不同時，下方加註「本期」 |
| 出現密度 | 有發生的天數 ÷ 查詢天數；天天都有通常是背景雜訊 |
| 總次數 | 所有主機加起來的事件次數 |
| 最近出現 | 最近一次出現的日子；寫「昨日仍在發生」的優先看 |
| 處理概況 | 未處理、處理中、已處理各幾台。沒有人標記、只因嚴重度不用處理的，另寫「預設不處理」 |
| 處理人 | 誰在處理 |
| 已交辦 | 幾台已經交辦，沒有就寫「未交辦」 |

欄名旁有「?」圖示的，滑鼠移上去可看說明。

## 展開一個問題：看哪幾台已經連續多天

點問題那一列會在下方展開受影響的主機，一台一列。台數和該列的主機數相同。

- 「天數」：這台在查詢期間有幾天出現這個問題。到最後一天還有，會寫「仍在發生」。
- 「出現日」：每個日期都可以點，直接打開那一天的風險日詳情。
- 日期太多時只列最近 14 天，其餘點「另有 N 天」到明細查看。
- 點整列或「去處理」，會打開這台最近出現的那一天。

天數多的主機排在前面，先處理這些。

## 列上的按鈕

依你的權限會出現下面幾個動作。只有一兩個時都放在列上；三個以上時，列上留第一個，其餘點「更多」打開。

- 「回覆處理狀態」：一次回覆你名下這個問題的全部交辦單。
- 「交辦」：把這個問題派給處理人。
- 「統一標記」：替還沒人接手的主機一次下結論。要自己選結論並填原因，才能套用。
- 「靜音」：這個問題暫時不看，到期自動恢復。原因必填。
- 「不再顯示這個問題…」：回答三個問題，系統選對應的做法並先說明後果。
- 「調整這條規則」：直接打開命中的規則來編輯，沒有命中規則的問題沒有這個選項。

「回覆處理狀態」要有處理權限，且是自己名下的問題。
「交辦」只有系統管理員看得到。
「靜音」「不再顯示這個問題…」「調整這條規則」要有系統維護權限。
主機負責人也看得到「統一標記」，但只會標到自己負責的主機。
其他主機會被略過，原因寫「不是你負責的主機」。
主機負責人的視窗裡沒有「之後新出現的主機日也自動套用」，那是系統管理員的決定。

在「依問題」角度還有「未指派」篩選，只看沒人負責的問題。
交辦與回覆見「處理狀態與交辦單」。靜音等工具怎麼選見「讓告警安靜的工具」。

「依主機」「依日期」角度不能用處理狀態、未指派、逾期篩選。「依問題」角度不能用逾期篩選。切過去時，條件列會寫「目前的檢視不支援」，並列出被略過的條件。切回明細就會恢復。

## 「不再顯示這個問題…」怎麼選

在問題那一列的「更多」點「不再顯示這個問題…」，依序回答：

1. 多久：「暫時」（選 1 到 365 天）或「長期」。
2. 範圍：「全站」、「指定主機群組」或「單一主機」。
3. 已交辦的單：「暫停」、「代為結案」或「不動」。問題沒有進行中的單時不會問這題。

選好後，畫面先寫會發生什麼事，確認才套用。
暫時加全站是靜音，長期加全站是機房結論，指定群組或單一主機是規則抑制。
問題沒有對應規則時，沒有群組與單一主機可選，畫面會說明原因。
列表上方的「不再顯示這個問題：選哪一種」比較表，可以先看六種做法的差別。

## 其他功能

- 「複製為 CSV」：把目前這一頁的結果複製成表格文字，可貼到 Excel。其他頁的列不會一起複製。
- 「AI 歸納」：只在「明細」角度出現。AI 用一段話說明這批結果最值得注意的地方。AI 沒設定時不會出現。
- 歸納沒有成功時，結果表上方的歸納區會出現一行提示，先前的歸納內容會保留。稍後再按一次即可。

## 常見狀況

- 只篩一個風險層級時，其他層級的欄位寫「—」，不是 0。因為那些資料已被篩掉。
- 列表上方寫「另有 N 個問題靜音中（未列出）」：有問題正在靜音，所以沒列出。
- 每列主機數加起來比儀表板卡片多：同一台主機會出現在好幾列。對照卡片時，看列表上方的「共 N 台主機（去重）」。
- 想看某一天的完整內容：在「明細」角度點那一列，進入「風險日詳情」。
