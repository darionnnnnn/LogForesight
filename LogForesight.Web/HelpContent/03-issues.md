# 問題事件

「問題查詢」頁可以跨主機、跨日期找問題，不必先點進某台主機。
側欄位置是「監控作業 > 問題查詢」。

## 常用操作：找出某個問題

1. 在「主機」輸入名稱搜尋，可選多台；不選就是全部。
2. 選期間，或用快捷鈕（昨日、近 7 天、近 30 天、近 90 天）。快捷鈕的最後一天是昨天。
3. 需要時填「Event ID」（事件編號）或「來源（選填）」，例如 `disk`。
4. 點選「套用」。要重來就點選「清除條件」。
5. 點任一列，打開那台主機那一天的「風險日詳情」。

表格上方還可以依風險層級、風險類型、主機群組再縮小範圍。

## 切換檢視角度

| 按鈕 | 每一列是 | 適合 |
|---|---|---|
| 依問題 | 一個問題，跨所有主機彙總 | 找出影響最廣的問題、交辦、靜音 |
| 明細 | 一台主機一天的一個問題 | 逐筆追查 |
| 依主機 | 一台主機 | 看哪台主機問題最多 |
| 依日期 | 一天 | 看哪天特別嚴重 |

**注意：**在「依問題」角度，高／中／低篩的是「問題嚴重度」。
其他角度篩的是「風險層級」，也就是那一天的整體風險。畫面上的標籤會跟著變。

## 看懂「依問題」的欄位

問題名稱下方有一行白話說明。分類是「其他」代表沒有命中任何規則，可以到「規則維護」替它建規則。
問題有指派負責人時，名稱旁會出現「負責人」徽章。

| 欄位 | 意思 |
|---|---|
| 主機數 / 主機日 | 幾台主機出現過；總共幾個「主機×天」 |
| vs 基準 | 這次影響台數 ÷ 平常的台數，紅色「擴散」要優先看 |
| 首見 | 整個機房第一次出現的日子；本期第一次出現的日子不同時，下方加註「本期」 |
| 出現密度 | 有發生的天數 ÷ 查詢天數；天天都有通常是背景雜訊 |
| 總次數 | 所有主機加起來的事件次數 |
| 處理概況 | 未處理、處理中、已處理各幾台 |
| 處理人／已交辦 | 誰在處理；幾台已經交辦，沒有就寫「未交辦」 |

欄名旁有「?」圖示的，滑鼠移上去可看說明。

## 列上的按鈕

依你的權限會出現：

- 「交辦」：把這個問題派給處理人。
- 「統一標記」：替還沒人接手的主機一次下結論。
- 「靜音」：這個問題暫時不看，到期自動恢復。
- 「回覆處理狀態」：一次回覆你名下這個問題的全部交辦單。

在「依問題」角度還有「未指派」篩選，只看沒人負責的問題。

「依主機」「依日期」角度不能用處理狀態、未指派、逾期篩選。切過去時，條件列會寫「目前的檢視不支援」並列出被略過的條件；切回明細就會恢復。
交辦與回覆見「處理狀態與交辦單」；靜音等工具怎麼選見「讓告警安靜的工具」。

## 其他功能

- 「複製為 CSV」：把目前結果複製成表格文字，可貼到 Excel。
- 「AI 歸納」：AI 用一段話說明這批結果最值得注意的地方。AI 沒設定時不會出現。

## 常見狀況

- 列表上方寫「另有 N 個問題靜音中（未列出）」：有問題正在靜音，所以沒列出。
- 每列主機數加起來比儀表板卡片多：同一台主機會出現在好幾列。對照卡片時，看列表上方的「共 N 台主機（去重）」。
- 想看某一天的完整內容：點那一列，進入「風險日詳情」。
