# PRTG 維護

PRTG 維護頁只供維護人員使用，側欄位置是「系統管理 > PRTG 維護」。頁面有「連線」、「擷取參數」、「鏡像狀態」和「環境探測」四個頁籤。

## 連線

在「連線」頁籤填入 PRTG 位址，選擇認證方式，再按「測試連線」確認。支援「API token（推薦，PRTG 21+）」、「帳號密碼（PRTG 傳統 API / passhash）」和「帳號＋passhash」。測試成功後按「儲存」。

## 擷取參數

「PRTG 擷取（數值取數對象）」決定是否啟用 PRTG 取數，以及取數範圍。可選「關閉（預設）」、「只抓觸發主機」、「全部已對應主機」或「觸發主機＋指定清單」。另可設定取數策略、請求逾時、併發請求數、歷史回填天數、資料保留天數與 sensor type 白名單。

「保守（預設）」以快照供應數值；「激進」會對觸發主機逐顆查詢歷史值。儲存後可按「估算規模」查看主機、device、sensor 與保留量級。

資源守門已移到「系統管理 > 設定 > 資源守門」，PRTG 維護頁的連結會帶你前往該頁籤。

## 鏡像狀態

按「同步結構與對應」更新 PRTG 裝置、sensor、主機對應與狀態。頁面會列出成功對應、衝突、未對應、排除 IP 與目前鏡像數量。衝突列可依「衝突型別」選取後指派主機；不確定是否應清除資料時，先看取數範圍與同步結果。

同步完成後，監看裝置鏡像依完整裝置同步結果判定；sensor 鏡像依「數值取數對象」的取數範圍判定。只有在完整同步與主機對應都成功、監看裝置範圍非空且不是部分處理、裝置鏡像本趟確實更新，並且已有監看裝置數基準、這次數量減少沒有超過縮小保護門檻時，系統才會立即清除不再屬於目前取數範圍的數值與狀態變更。首次沒有基準，或監看裝置數驟減而觸發縮小保護時，不自動清除；請在本頁「監看範圍外資料」先看預覽，再按「確認清除」人工處理。範圍計算失敗、空範圍、部分處理或裝置鏡像未成功更新時也不清除。歷史值補抓請到「PRTG 維護」頁；「排程作業」只查看 PRTG 狀態與執行中的停止鈕。

## 環境探測

環境探測是唯讀工具，用來確認 API 回應、分頁、狀態變更查詢、數值查詢、取數範圍和資源守門目標。首次啟用或調整取數範圍前先執行，特別查看「9d-5 逐物件查詢驗證」與「站台對照」。探測遇到連線、認證或逾時會顯示原因，不把量不到當成零資料。

探測結果仍需依現場的 PRTG 版本、sensor 分類、裝置數量與網路延遲判讀；頁面顯示的估算不能取代夜間實機執行確認。
