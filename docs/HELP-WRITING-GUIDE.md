# 操作說明書寫作規範

適用 `LogForesight.Web/HelpContent/` 的章節檔。目標讀者是**不懂 IT 的值班人員與處理人**：打開章節一分鐘內知道「這頁做什麼、我先按哪裡」。
呈現方式與渲染限制見 docs/WEB-SPEC.md §9.9c；全站用詞見 §8.6a。

## 1. 兩種檔案，兩種寫法

| | 使用者版 `NN-xxx.md` | AI 版 `NN-xxx.ai.md` |
|---|---|---|
| 誰讀 | 畫面上的人 | 說明書問答的 AI（不顯示在畫面） |
| 寫法 | 本規範全部適用 | 可詳細：門檻、狀態流轉、權限差異、常見誤解 |
| 共同底線 | 事實與程式碼一致；用詞與使用者版相同；兩版不得互相矛盾 | 同左 |

## 2. 章節骨架（使用者版）

依序，用不到的段落省略：

1. `# 章節名`：與 manifest `title` 相同。
2. **開場兩句**：這頁用來做什麼；從哪裡進來（側欄路徑）、誰看得到。
3. `## 常用操作`：最常做的事，用編號步驟（1. 2. 3.），一步一個動作。
4. `## 看懂畫面`：欄位、狀態、顏色代表什麼，比較多項時用表格。
5. `## 常見狀況`：「看到 X → 代表什麼 → 怎麼做」。
6. `## 注意事項`：不可逆操作、權限限制、資料可見性後果。

每個 `##` 段落以 **6 行內**為原則；超過就拆段或改成表格。整章以 **一個螢幕捲動 3 次內**看完為目標。

## 3. 句子

- 一句一件事，**30 字內**為原則、不超過 45 字。長句拆開，不用分號串接。
- 先講結論或動作，再講原因。原因一句就好，不寫設計理由與取捨過程。
- 用「你」稱呼讀者，用主動句：「點選『儲存』」，不寫「設定將會被儲存」。
- 不寫沿革：禁用「原本／過去／後來／改為／已不存在／本版／第 N 輪」。只寫現在的樣子。
- 不寫實作：類別名、API 路徑、資料表、blob 鍵、設定鍵（如 `AiConcurrency`）、演算法名稱不進使用者版。
  使用者會在畫面看到或要自己輸入的字（欄位名、檔名、CSV 欄位）例外。
- 數字只寫使用者用得到的：預設值、上限、要等多久。

## 4. 用詞

- **畫面上的字一字不差**，用「」框起來：按鈕、頁籤、欄位、狀態、提示文字都照 View／JS 實際文案。
- 導覽路徑寫成「系統管理 > 規則維護」，名稱以 `wwwroot/js/core/layout.js` 的 `label` 為準。
- 動作用「點選」、檢視用「檢視」；不用陸詞（見 §8.6a）。
- 同一個東西全站同一個名字，以 13-glossary.md 與下表為準，不自創同義詞：

| 用這個 | 意思 | 不要混用 |
|---|---|---|
| 主機日 | 計數單位：一台主機的一天（例：待補 12 主機日） | 記錄日、筆 |
| 風險日詳情 | 頁面名；點進某台主機某一天看到的頁 | 主機日詳情、紀錄頁 |
| 交辦單 | 處理人看到的工作單位 | 處理人章節不寫「案件」（管理章節才用） |
| 靜音 | 問題層級、有期限，到期自動恢復 | 「告警抑制」是另一個功能 |
| 告警抑制 | 規則維護頁的抑制設定 | 抑制規則、靜默 |
| 處理狀態 | 未處理／處理中／已處理等 | 案件狀態 |
| AI 分析 | 功能與排程卡的名稱（「AI 分析」卡、「AI 分析」排程） | 畫面寫「AI 判讀」的地方照畫面 |

表外的詞：畫面怎麼寫就怎麼寫；同一章內同一個東西只用一個名字。

- 英文只留產品名與畫面上就是英文的字（NetIQ、PRTG、AI、Event ID、CSV）。
  第一次出現的專業詞用一句白話解釋，例如「Event ID（Windows 事件的編號）」。

## 5. 排版（受 markdown-lite 限制）

- 只用：`#`／`##` 標題行、單層清單（`-` 或 `1.`）、表格、**粗體**、行內代碼。
- **不用**：`###` 以下標題（呈現上與 `##` 相同，只會打亂層次）、巢狀清單、引用 `>`、連結語法。
- 操作步驟一律編號清單；並列項目用 `-` 清單；兩項以上的比較用表格（**4 欄內**）。
- 粗體只標「做錯會出事」的那一句，每段至多一處。
- 段落之間空一行；不用連續空行。
- 警告寫成一行開頭的「**注意：**」，放在相關步驟旁，不集中堆在章末。

## 6. 正確性

- 每個畫面文字、預設值、上限、權限說法都要在程式碼找得到（View、`wwwroot/js`、Controller、`SystemSettings` 預設值）。
- 功能被移除就刪掉那段，不寫「已不存在」。
- 改了使用者版的事實，同一次更新 AI 版對應段落。
- 驗證：`dotnet test --filter "FullyQualifiedName~Help"`（章節載入、導覽名稱、處理人章節不洩漏管理用詞）。
