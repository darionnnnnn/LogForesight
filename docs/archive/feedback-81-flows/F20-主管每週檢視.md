# F20 主管每週檢視與報告

- 角色／目標：主管看整體風險與處理成效，找出卡住的地方，產出給上級的報告。
- 頻率：每週。
- 對應測試項目：R3、P10、K1、K3；既有發現：K1、K3、M1、M2、D4。
- 現行步數：儀表板 → 報表（三視角）→ 列印／存 PDF ≈ 4 步。步數少，問題在數字能不能直接拿去用。

## 逐步思考

### F20-1 整體狀況
- 需要知道：風險在升還是降、哪些問題最大、處理跟不跟得上。
- 畫面有給嗎：報表總覽有趨勢、處理進度、主機與問題排行、對比前一期。
- 情境：量大——「未結案 2,026」是主機日且含不派工的中低風險日，對不上處理人佇列的 188 件（K3）；主管無法回答「我們積了多少」。
- 判斷：補資訊。
- 建議：處理成效第一行直接回答三個問題：**在處理人手上 N 件（最久 X 天）、待派 N 件、不需處理 N 主機日**。

### F20-2 找出卡住的地方
- 需要知道：哪個團隊、哪個人、哪個問題卡最久。
- 畫面有給嗎：部分。依群組風險概況（儀表板）；負載看板在交辦總覽（主管可看、唯讀）。報表沒有「依處理人／依群組的處理時效」。
- 判斷：補資訊。
- 建議：處理成效加「依處理人群組」的回覆時效與未回覆數（資料同負載看板）。
- 新發現 **F20-2**。

### F20-3 復發
- 畫面有給嗎：有「結案後再發生」與前 10 名問題（D2：106/106 組）。這是找出「該調規則或換硬體」的好線索。
- 判斷：保留；可從這裡連到 F16、F19。

### F20-4 產出報告
- 畫面有給嗎：列印／存成 PDF、大螢幕模式、圖表可切表格。沒有 CSV／Excel 匯出（問題查詢只有「複製為 CSV」且只含當頁）。
- 未實測：列印版面。
- 判斷：補資訊。
- 建議：報表各表提供下載 CSV（整份、不限當頁）。
- 新發現 **F20-4**。

### F20-5 唯讀角色看到的操作暗示
- 未讀徽章消不掉（M1）、未回報主機卡是死路（D4）。
- 判斷：省略。

## 目標流程
步數不變；首屏三個數字能直接對應行動，報表可匯出。
