# 第 78 輪工作檔

第 78 輪（3000 台規模的效能最佳化，不改運作邏輯）的過程記錄。現行結論在 `docs/FEEDBACK-78-PLAN.md` 與各現行規格；這裡只供換模型體檢與追查來龍去脈時對照。

- `scan/`：規劃前四條流程的唯讀盤點報告（Sonnet 5.5 產出，主代理複核過關鍵事實；行號是當時 dev@1e304931 的位置）。
  - `A-nightly-fetch.md`：夜間取數主流程（排程觸發到主機日寫入），含每主機日的資料庫命令清單。
  - `B-prtg.md`：PRTG 每日路徑與快照服務。
  - `C-post-fetch.md`：掛接派工、郵件、AI、工作流恢復、資料保留，含工作流狀態的完整讀寫表與父指紋呼叫點。
  - `D-interactive-cache.md`：互動查詢路徑與全站快取、資料版本戳的推進點。
- `specs/`：各段交給 subagent 的實作規格（契約、白名單、驗收）。檔名對應規劃文件的批次：
  `spec-batch0.md`～`spec-batch5c.md`。實作結果與偏離規格之處記在規劃文件的「執行紀錄」。
- `review/`：實作方自查的三路獨立唯讀體檢報告（R1 郵件與工作流、R2 PRTG 與夜間、R3 互動查詢與快取）。
- `review2/`：第二次實作方自查，依使用者角色切三路的報告（U1 網頁使用者、U2 維運與夜間排程、U3 部署升級／SQL Server／測試品質）。
  每條發現的處置（修正或評估後不改）記在規劃文件的「實作方自查」；換模型體檢可略過已處置的項目。
